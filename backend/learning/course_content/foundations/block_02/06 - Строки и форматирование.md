# Строки и форматирование

Научимся отличать количество символов от их позиций, получать фрагменты строки и сохранять результат текстового метода.

**Темы:** длина и индексы · срезы · методы строк · f-строки

## 00. От строки к подготовленному тексту

1. **Точка старта.** В прошлой работе мы получили текст через `input()`, преобразовали количество занятий в число и рассчитали минуты, часы и остаток.
2. **Новый вопрос.** Как подготовить отдельное название сессии, сохранив его смысл и введённый регистр?
3. **Результат.** Мы научимся находить часть строки и сохранять результаты методов, а затем добавим название к существующему расчёту.

В прежнем проекте строка уже была входом программы: `input()` возвращал текст, а перед умножением мы явно превращали количество занятий в целое число. Теперь посмотрим на строку подробнее. В конце мы применим те же знакомые присваивания, ввод и вывод к названию сессии, не переписывая формулу времени.

## 01. Длина отвечает на вопрос о количестве

Строка содержит символы в определённом порядке. Функция `len()` сообщает их количество, но не выбирает отдельный символ. Для позиции используем индекс, который начинается с нуля.

Представим три подписанных ящика в ряд. Количество ящиков равно трём, а их номера идут от 0 до 2. В строке действует такое же различие: длина отвечает «сколько?», индекс отвечает «какой символ стоит здесь?». Для строки `"Git"` длина равна 3, но последний индекс равен 2. Номер последнего символа можно найти как длина минус один.

```python
title = "Git"
print(len(title))
print(title[0])
print(title[2])
print(title[-1])
```

Индексы слева направо равны 0, 1 и 2, а индекс `-1` обозначает последний символ. Отрицательный индекс отсчитывает позиции от конца: `-1` выбирает последний знак, `-2` предыдущий. Это удобный способ обратиться к краю непустой строки, но он не создаёт символ в пустой строке.

**Предскажем результат для пустой и односимвольной строки:**

```python
print(len(""))
print(len("A"))
print("A"[-1])
```

**Результат:**

```text
0
1
A
```

Пустая строка не содержит символов, поэтому у неё нет допустимого индекса ни 0, ни -1. Односимвольная строка имеет только индекс 0 и -1. Мы не будем автоматически брать первый знак произвольного ввода: сначала нужно знать, что строка непустая. Для безопасного короткого фрагмента познакомимся со срезом.

Пробел тоже является символом строки и занимает свою позицию. Поэтому текст с пробелом по краям может иметь длину больше, чем название без этих пробелов. Функция `len()` честно считает всё содержимое, а решение убрать края мы примем отдельно с помощью метода, который подходит для этой цели.

## 02. Индекс выбирает один символ

Индекс в квадратных скобках выбирает одну позицию. Если мы запросили несуществующую позицию, Python сообщает `IndexError`. Ошибка указывает на границу данных, а не на поломку строки.

```python
title = "Git"
print(title[3])
```

В строке `"Git"` длина равна 3, но допустимы только индексы 0, 1 и 2.

**Почему этот код запрашивает несуществующий символ?**

- A. Длина равна 3, поэтому допустимы индексы 0, 1 и 2
- B. Индекс нужно записать строкой
- C. `print()` не принимает строки

Ответ: A. Количество символов равно 3, но нумерация начинается с 0. Последний индекс равен 2.

```python
title = "Git"
print(title[-1])  # t
```

Число 3 удобно для счёта, но в строке `"Git"` оно уже за правым краем: существующие номера 0, 1 и 2. Исправим пример, выбрав допустимую позицию. Если нам нужен крайний символ ввода любой длины, нельзя заранее подставить один индекс для всех возможных случаев; длина помогает понять границы, а срез позволяет безопасно взять фрагмент.

Если строка приходит от человека, заранее неизвестно, сколько в ней символов. Запрос `title[0]` сработает только для непустого значения, а для пустого завершится ошибкой. Пока мы не изучили условие, не будем придумывать обходной выбор. Вместо этого мы можем показать ошибку на известной строке и выбрать срез там, где нужен фрагмент переменной длины.

## 03. Срез получает фрагмент строки

Срез записывается как `text[start:end]`. Левая граница входит в результат, правая показывает место остановки и не входит.

Представим, что мы отмечаем на ленте начало и конец нужного фрагмента двумя чертами. Срез включает символы после левой черты, а на правой останавливается до символа под этой чертой. Поэтому `"backend"[0:4]` даёт `"back"`: позиции 0, 1, 2 и 3 включены, позиция 4 уже служит границей остановки. Такой договор помогает точно выбирать часть строки, не включая соседний знак.

**Передвинем границы среза:**

```python
"backend"[0:4]  # "back"
"Python"[:3]    # "Pyt"
"Python"[3:]    # "hon"
```

Пропущенное начало означает позицию 0, а пропущенный конец означает конец строки. Поэтому `"Python"[:3]` берёт три первых знака, а `"Python"[3:]` начинает с позиции 3 и идёт до конца. Если границы равны, между ними нет символов и результат пустой. При правой границе дальше длины срез просто остановится у конца.

```python
print("Python"[:3])
print("Python"[2:2])
print("Git"[0:20])
print(""[:3])
```

Результаты по порядку: `Pyt`, пустая строка, `Git` и пустая строка. В отличие от одиночного индекса, срез за длиной не вызывает `IndexError`. Это полезно для короткого или пустого пользовательского ввода, когда фрагмент может оказаться короче ожидаемого.

Срез тоже вычисляет строковое значение. Например, `first_part = title[:1]` сохраняет первый символ, если он есть, но не меняет `title`. Для пустого названия этот срез просто даст пустую строку. Здесь нам не нужны ни обязательное обращение к индексу, ни условие только ради безопасного чтения начала.

**Почему правая граница среза не входит в результат?**

В `text[0:4]` входят позиции 0, 1, 2 и 3. Позиция 4 задаёт место остановки, поэтому получается `back`.

## 04. Метод создаёт новый текст

Метод вызывается у значения через точку и круглые скобки. Строковый метод создаёт результат, а исходная строка остаётся прежней, пока мы не присвоим новое значение имени.

Точка связывает действие с конкретным текстом: `text.upper()` просит строку в `text` создать вариант с заглавными буквами. Скобки запускают действие. Если нам нужен результат дальше, связываем его с именем, как связывали с именами числа в прошлой теме.

Представим бумажную карточку с исходной подписью и новую копию, на которой подготовили надпись для показа. Мы не стираем оригинал незаметно: можем сравнить обе версии или выбрать, какую из них оставить под именем `title`. В Python строка тоже не меняется по частям на месте. Метод создаёт другую строку, а присваивание решает, где сохранить этот новый результат.

```python
text = "python"
text.upper()
print(text)
upper_text = text.upper()
print(upper_text)
```

Ход выполнения:

1. Сохраняем исходную строку `"python"`.
2. Метод создаёт новый текст `"PYTHON"`, но результат пока не сохраняем.
3. Выводится исходное значение `python`.
4. Сохраняем новый результат под отдельным именем `upper_text`.
5. Выводится сохранённая новая строка `PYTHON`.

На втором шаге вызов `text.upper()` создаёт текст `"PYTHON"`, но строка в `text` остаётся `"python"`. Поэтому следующий `print(text)` показывает исходный вариант. Когда мы пишем `upper_text = text.upper()`, отдельное имя удерживает результат. Пока достаточно понимать это как результат метода; свои функции и слово `return` мы разберём позже.

При записи `title = title.strip()` Python сначала вычисляет правую часть и получает новую строку, а затем связывает имя `title` с этим результатом. Исходный текст как объект не меняется. Если нам важно хранить оба варианта, дадим им разные имена, как в примере с `raw_title` и `title`.

```python
title = "python"
title[0] = "P"
```

В этом фрагменте мы пытаемся изменить строку на месте. Индекс подходит для чтения символа, но строка не поддерживает замену по индексу.

**Почему нельзя заменить букву присваиванием по индексу?**

- A. Строки неизменяемы
- B. Индекс 0 всегда пустой
- C. Буквы меняются только внутри `print()`

Ответ: A. Индекс строки подходит для чтения символа, но строка не поддерживает замену символа на месте.

```python
title = "python"
title = "P" + title[1:]
```

Квадратные скобки подходят для чтения символа, но присваивание в `title[0]` пытается заменить часть неизменяемой строки. Вместо этого соберём новую строку из нужной буквы и оставшегося среза. Мы сохраняем результат целиком в `title`; старый текст при этом не редактируется по символам.

## 05. Подготовим текст по его назначению

Методы `strip()`, `lower()` и `upper()` создают новый текст по разным правилам. Сначала определим, что именно должно измениться, и сохраним подходящий результат.

- `strip()` удаляет пробельные символы по краям строки; пробелы между словами остаются.
- `lower()` создаёт нижний регистр, если команда должна сравниваться без учёта регистра.
- `upper()` создаёт заглавное написание, если такой вид нужен короткому коду.

Пробелы в начале и конце часто остаются случайно после ввода. Метод `strip()` помогает убрать их только с краёв. Он не сжимает двойной пробел между словами и не выясняет, подходит ли текст программе. Название сессии нужно показать человеку, поэтому мы очистим края, но оставим регистр и внутренние пробелы.

```python
raw_title = "  Изучить SQL  "
title = raw_title.strip()
raw_command = "  CaLc  "
command = raw_command.strip().lower()
print(title)
print(command)
```

Здесь `raw_title` остаётся исходным вводом, а `title` хранит новую строку без краевых пробелов. Команду мы очищаем и переводим в нижний регистр, чтобы позже одинаково сравнить `CaLc` и `calc`. Мы задаём правила по назначению данных, а не применяем все методы подряд.

В цепочке `raw_command.strip().lower()` Python сначала получает результат `strip()`, затем вызывает `lower()` у этого нового значения и сохраняет последний результат в `command`. Переменная `raw_command` всё ещё содержит пробелы и исходный регистр. Можно разбить цепочку на два присваивания, если так легче проверить каждый промежуточный результат.

**Как подготовить название, если нужно убрать края и сохранить регистр?**

- Сохраняем регистр: `title = raw_title.strip()`. Краевые пробелы исчезают, а заглавные буквы остаются.
- Меняем регистр: `title = raw_title.strip().lower()`. `lower()` дополнительно переводит буквы в нижний регистр.

Для отображаемого названия сохраняем исходный регистр. `lower()` нужен для другого договора, например для сравнения команд без учёта регистра.

Вызов метода без присваивания снова оставил бы исходную переменную без сохранённого результата. Поэтому мы используем отдельные понятные имена: `raw_title` для того, что ввели, и `title` для подготовленного названия. В этой работе нам нужны `strip()` и правило регистра; универсальную проверку допустимости названия мы пока не строим.

Когда короткая метка должна выглядеть заглавными буквами, сначала выбираем нужную часть срезом, а затем применяем к ней `upper()`. Полное название при этом остаётся в отдельной строке с исходным регистром. Если исходный текст короче ожидаемой метки или пустой, срез безопасно даст доступную часть, а не ошибку индекса; это свойство не превращает метку в постоянный идентификатор записи.

## 06. F-строка собирает сообщение из значений

Буква `f` перед кавычками включает подстановку выражений из фигурных скобок. В шаблон можно вставить значение строки или числа; исходные переменные от этого не меняются.

```python
minutes_left = 25
message = f"Осталось {minutes_left} минут"
print(message)
```

В фигурных скобках пишем имя без кавычек: так Python подставляет текущее значение. Если мы уберём букву `f`, то `{minutes_left}` станет обычным фрагментом текста. F-строка собирает новое сообщение, но не меняет `minutes_left` и не превращает текст в новое число.

Текст шаблона остаётся за пределами фигурных скобок, а в скобках располагаются значения для подстановки. Поэтому можно написать сообщение, где рядом стоят название и результат расчёта, хотя один фрагмент имеет тип `str`, а остальные имеют числовые типы. Для показа Python представляет их в виде текста, но переменные `total_minutes`, `full_hours` и `minutes_left` продолжают хранить числа.

Кавычки внутри фигурных скобок тоже меняют смысл: имя без кавычек обозначает значение переменной, а имя в кавычках является буквальным текстом. Если мы случайно напишем незнакомое имя, Python сообщит об ошибке имени; поэтому перед запуском полезно сверить написание со строкой присваивания. Для знакомых переменных достаточно простой подстановки, без дополнительного синтаксиса форматирования.

**Подставим значение переменной в сообщение:**

```python
message = f"Осталось {minutes_left} минут"
```

В фигурных скобках нужно указать:

- `minutes_left`
- `"minutes_left"`
- `print`

Ответ: `minutes_left`. Имя без кавычек означает, что Python вставит значение переменной.

**Что изменится, если убрать букву `f` перед кавычками?**

Без `f` фигурные скобки и имя переменной останутся частью обычного текста. Значение переменной при этом не изменится.

В нашем проекте уже есть три числовых результата: общее количество минут, полные часы и остаток. Мы можем поместить их в один понятный шаблон рядом с очищенным названием сессии. Форматирование меняет только способ показа значений; умножение, сложение, целочисленное деление и остаток остаются прежними.

## 07. Что мы будем делать в практике

Сначала проверим строку на маленьких примерах и только после этого применим методы к прежнему проекту. Каждое действие даст наблюдаемый результат, по которому можно проверить наше объяснение.

1. **Исследуем.** Сопоставим длину, индекс и срез на обычной, короткой и пустой строке; увидим, какие запросы безопасны.
2. **Разберём.** Найдём причину ошибки границы и невозможности менять один символ; соберём новую строку и проследим метод с сохранением результата.
3. **Подготовим.** Применим разные правила к названию и команде, затем соберём короткую карточку из текста и числа.
4. **Продолжим проект.** Добавим очищенное название в существующий `main.py` и покажем его рядом с прежним расчётом в понятной f-строке.

В проекте проверим названия «Изучить SQL» и «SQL практика», чтобы убедиться: края очищены, а регистр и внутренние пробелы сохранены. При вводе количества 2 прежний расчёт по-прежнему даст 90 минут, один полный час и 30 минут остатка; после этого посмотрим `git diff` и сохраним проверенную правку в том же проекте.

Пустой текст после `strip()` сейчас останется пустым. Мы пока наблюдаем результат, но не будем отказывать во вводе или спрашивать название повторно: ветвление и повтор появятся в следующих занятиях.
