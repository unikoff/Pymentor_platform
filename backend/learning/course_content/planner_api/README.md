# Planner API

Markdown занятий распределён по папкам:

- `block_00`: карта обучения и теория месяца.
- `block_09`: занятия 45–50, от консольной команды к HTTP.
- `block_10`: занятия 51–56, Postman, FastAPI и Pydantic.
- `block_11`: занятия 57–62, схемы, CRUD и организация приложения.
- `block_12`: занятия 63–68, роутеры, тесты и финальный проект.

Практика находится рядом с Markdown: у каждого блока свои `manual.py`, `code_tasks.py` и `__init__.py`. Обзор использует `block_00/manual.py`. Каталоги курса собирает корневой `__init__.py` через обычные импорты.

`track.json.id` сохраняет прежний ID курса. Русские названия в интерфейсе и ID занятий не зависят от нового имени папки `planner_api`.
