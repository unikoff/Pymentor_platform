# Цикл for и последовательности

Разберём, как выполнить одно действие для каждого элемента строки, диапазона или списка и что происходит, когда элементов нет.

**Темы:** последовательность · `for` · `range`

## 00. От одного текста к нескольким шагам

До сих пор расчёт выполнял знакомые действия один раз: получал значение, проверял его и показывал итог. Но если нужно вывести отдельную строку для каждого занятия, копировать почти одинаковый код неудобно. Начнём с уже знакомого текста: в нём есть несколько символов в определённом порядке. Посмотрим, как Python передаёт их по одному и как тот же механизм работает с числовым диапазоном и списком.

1. **Точка старта.** Мы умеем читать строку, её длину и отступы. В проекте уже есть проверка количества и один расчёт.
2. **Новый вопрос.** Как повторить уже понятное действие для нескольких значений, не копируя его строку за строкой?
3. **Результат.** Мы объясним порядок обхода и добавим к существующему расчёту шаги по реальному количеству занятий.

Какое повторяющееся действие могло бы появиться в расчёте занятий? Для каждого занятия можно показать отдельный шаг. Сначала разберём обход на независимых значениях, а затем добавим такой вывод в прежний расчёт, не меняя его формулу.

## 01. Строка хранит упорядоченные символы

Под последовательностью будем понимать несколько значений, расположенных в определённом порядке. Строка подходит для первого примера: её элементы это символы, и мы уже умеем получать их количество с помощью `len`. Вся строка, отдельный символ и длина строки связаны, но это разные значения. В `"кот"` вся строка состоит из трёх символов, а `"о"` является одним из них.

- **Вся строка:** `text = "кот"` хранит три символа в заданном порядке: сначала «к», затем «о», затем «т».
- **Один элемент:** `symbol = "о"` обозначает один элемент исходной строки.
- **Количество:** `len("кот")` возвращает `3`, а длина пустой строки равна `0`.

Представим последовательность как ряд карточек, на каждой записан один символ. Весь ряд это строка, порядок карточек задан, а в руках у нас в каждый момент только одна текущая карточка. Эта аналогия помогает разделить исходную последовательность и элемент, который обрабатывается сейчас. Она не означает, что Python физически вынимает или удаляет символы: строка остаётся прежним значением, а цикл по очереди получает её элементы.

Запись `for` задаёт повтор для элементов последовательности. После слова `for` мы пишем имя переменной, которой на текущем шаге будет присвоен очередной элемент. Слово `in` связывает это имя с источником значений. Двоеточие открывает тело, а отступ показывает, какие строки должны выполниться на каждом шаге. Поэтому `print` с отступом относится к циклу.

На схеме проследим одну связь: источник сохраняет порядок, цикл передаёт текущий элемент в тело и после обработки запрашивает следующий. Когда значения закончатся, выполнение продолжится после цикла.

Пустой источник сразу ведёт к строке после цикла: тело не запускается. Цикл не удаляет переданный элемент и не создаёт для него отдельную копию списка. Он лишь даёт переменной одно текущее значение за проход.

```python
for symbol in "кот":
    print(symbol)
```

Проследим выполнение. На первом шаге переменной `symbol` присваивается `"к"`, после чего тело печатает этот элемент. Затем цикл возвращается к заголовку, получает `"о"` и повторяет ту же строку тела. На последнем шаге переменная получает `"т"`. Когда символы заканчиваются, цикл завершается.

У цикла нет заранее написанных трёх копий `print`. Python выполняет тело, возвращается к заголовку и получает следующее значение. Имя `symbol` используется повторно: оно хранит текущий символ, а не всю строку и не список результатов. Когда источник исчерпан, следующая команда выполняется уже после блока.

## 02. Пустая строка, один символ и несколько шагов

Количество проходов задаётся количеством элементов в источнике, а не отдельным числом повторов в теле. У строки из одного символа будет один проход, у строки из трёх символов три, а у пустой строки ноль. Пустой обход является нормальным результатом, а не ошибкой цикла.

```python
for symbol in "Я":
    print(symbol)
```

В строке один элемент. Переменная цикла получает его, затем тело выполняется один раз и выводит `Я`. Сколько раз выполнится тело для пустой строки `""`? Ни разу: в пустой последовательности нет элемента для первого шага, поэтому Python сразу продолжит выполнение после блока цикла.

После обхода пустой строки нельзя считать, что цикл присвоил новое значение переменной `symbol`. Мы не вошли в тело, значит на шаге не было присваивания. Если имя не получило значение раньше, обращение к нему вызовет ошибку; если получило, в нём останется прежнее значение. Пустой цикл не создал новый результат.

Перед разбором полезно заранее назвать длину входа и ожидаемое число строк вывода. Если длина равна нулю, тело пропускается целиком. Если длина равна единице, повторного прохода нет. Так мы не будем ошибочно ожидать, что цикл всегда запускается хотя бы один раз.

## 03. range задаёт последовательность чисел

Для чисел используем `range`. Он задаёт последовательность значений для обхода, хотя готовый список при этом не создаётся. С одним аргументом `range(stop)` начинает с нуля и идёт до числа перед `stop`. С двумя аргументами `range(start, stop)` начинает с `start` и также останавливается перед `stop`. По умолчанию соседние значения отличаются на единицу.

- `range(0)` не содержит значений.
- `range(1)` содержит `0`.
- `range(3)` содержит `0, 1, 2`.
- `range(2, 5)` содержит `2, 3, 4`.

Во всех непустых случаях мы останавливаемся до правой границы. Поэтому `range(2, 5)` начинается с `2` и выдаёт `2, 3, 4`, а число `5` не входит.

```python
for number in range(2, 5):
    print(number)
```

Вывод будет таким:

```text
2
3
4
```

Границу можно представить как отметку на маршруте: стартовая отметка включена, а отметки остановки уже нет среди посещённых. Это помогает не добавлять `stop` вручную и не терять первый элемент. В самом Python правило точное: начальное значение включается, конечная граница исключается.

Диапазон описывает, какие числа идут: начало, остановку и в этом уроке шаг, равный единице. Цикл получает из этого описания очередное значение. Поэтому `range(3)` не является списком `[0, 1, 2]`, хотя обход выдаст те же числа по порядку. Для нашей задачи не нужно заранее создавать отдельную коллекцию чисел.

При `range(3)` переменная цикла последовательно получает `0`, `1` и `2`. Чтобы получить три значения, последнее должно быть меньше трёх. При `range(0)` тело не запускается. Диапазон не подтверждает допустимость пользовательского ввода: если проект должен отклонить отрицательное количество, это проверяется знакомым `if` до `range`, а не скрывается пустым обходом.

## 04. Минимальный список и прямой обход

Список служит ещё одним упорядоченным источником. Запишем его элементы в квадратных скобках и разделим запятыми. В этом занятии достаточно строк и пустого списка. Элементы остаются в записанном порядке, длина равна их количеству, а одинаковый текст в двух местах всё равно занимает два места.

```python
languages = ["Python", "Git"]
empty_languages = []
print(len(languages))        # 2
print(len(empty_languages))  # 0
```

Циклу можно передать сам список:

```python
languages = ["Python", "Git"]
for language in languages:
    print(language)
```

Сначала имя `language` хранит строку `"Python"`, затем `"Git"`. Поэтому мы печатаем текущий элемент напрямую. Python не добавляет в эту переменную его порядковое место. Если одна и та же строка записана два раза, она будет передана дважды, потому что цикл обрабатывает каждое место списка по порядку.

Здесь полезно различать список целиком, значение текущего элемента и позицию элемента. Прямой обход передаёт сам элемент, а позицию автоматически не сообщает. Позже позиция и постоянный идентификатор записи будут решать другие задачи, поэтому сейчас не станем вводить их без необходимости.

Для пустого списка результат такой же, как для пустой строки: ни одного элемента, ни одного прохода и никакого вывода из тела. Для непустого списка число проходов совпадает с `len`. Можно заранее посчитать элементы и предсказать, сколько раз появится строка внутри цикла.

## 05. Тело цикла и действие после обхода

Цикл не заменяет ветвление. `if` проверяет условие и выбирает, выполнять ли блок в этом месте программы. `for` получает источник элементов и повторяет тело для каждого из них. Условие выбирает путь, а последовательность задаёт число и порядок повторов.

```python
if lesson_count > 0:
    print("Есть занятия")
```

Этот `if` один раз проверяет условие и выбирает, запускать ли блок.

```python
for number in range(lesson_count):
    print(number)
```

Этот `for` запускает одну строку тела отдельно для каждого числа. Если знакомая проверка разрешила расчёт, цикл выполнит вывод по диапазону. Сам `if` не повторяется для каждого шага, а `for` не решает, допустимо ли значение.

Отступ определяет границу повторяемой части. Все строки с одинаковым отступом под заголовком `for` выполняются на каждом проходе. Строка без этого отступа находится после цикла и запускается один раз, когда источник закончился. Если источник пуст, тело пропускается, но строка после цикла всё равно выполнится.

В первом ошибочном фрагменте текущий элемент используют как позицию:

```python
languages = ["Python", "Git"]
for language in languages:
    print(languages[language])
```

После каждого прохода `language` уже хранит текущую строку. Обращение `languages[language]` использует её как позицию списка, а нам нужно напечатать само значение. Исправим так:

```python
for language in languages:
    print(language)
```

Во втором фрагменте сообщение находится внутри цикла:

```python
for symbol in "код":
    print(symbol)
    print("Готово")
```

Пока `print("Готово")` находится в теле, он повторяется для каждого символа. Если убрать отступ, команда станет следующей после цикла и выполнится один раз, в том числе при пустом тексте:

```python
for symbol in "код":
    print(symbol)
print("Готово")
```

В прямом обходе для каждого элемента достаточно самого значения. Если когда-нибудь понадобится его позиция, её нужно будет получить отдельным способом, а не считать, что цикл присвоил её автоматически.

## 06. Шаги в существующем расчёте

Применим механизм к прежнему проекту. В ветке `calc` уже есть введённое количество занятий, проверка допустимости и расчёт времени. Новая строка вывода должна появиться для каждого занятия. Цикл разместим после проверки количества и перед знакомой формулой. Так недопустимое отрицательное значение не превратится незаметно в пустой диапазон.

Перед проектной правкой разберём независимый пример:

```python
for number in range(3):
    print(number)
```

`range(3)` передаёт числа `0`, `1` и `2` по порядку. Тело печатает отдельную строку для каждого числа. После `2` диапазон заканчивается перед `3`.

Значения в `range(3)` начинаются с нуля, а подпись человеку обычно удобнее читать от первого занятия. Поэтому в отображаемой подписи используем знакомое арифметическое смещение на единицу. Оно меняет только номер на экране: количество проходов по-прежнему равно трём. Отдельный список занятий не нужен.

Число, полученное для количества занятий, остаётся исходным значением. Цикл не уменьшает его и не записывает в него текущий номер. На каждом проходе меняется только переменная цикла, а знакомая формула по-прежнему использует само количество. Так пошаговый вывод не меняет смысл прежнего расчёта.

Для количества `0` тело не выполнится, а после цикла нельзя обращаться к переменной шага так, будто она обязательно получила значение. При этом сам расчёт продолжает выполняться по прежней формуле, которая не зависит от переменной цикла. Для количества `1` ожидаем одну строку шага, для `3` три строки. Это проверяет число проходов, но пока не меняет итоговые минуты.

Не будем смешивать два результата. В этом занятии цикл показывает отдельные шаги и обходит уже известное количество. Чтобы получить сумму разных длительностей или сохранить состояние между итерациями, понадобится отдельная идея: начальное значение, обновление на каждом шаге и чтение итога после цикла. К ней перейдём дальше. Пока формула, часы, остаток и правило одного перерыва остаются на прежнем месте.

## 07. Что мы будем делать в практике

Сначала проверим механику на коротких входах и предскажем вывод до запуска. Затем продолжим реальный расчёт, добавим в разрешённую ветку повторяющиеся шаги и убедимся, что прежний результат не потерялся.

1. **Спрогнозируем обход.** Сверим элементы строки и значения `range` с порядком и числом будущих строк вывода.
2. **Проверим прямой список.** Сохраним порядок и повторы, обработаем пустой вход и исправим путаницу между элементом и позицией.
3. **Продолжим `main.py`.** Внутри проверенной ветки `calc` выведем шаги по введённому количеству, не создавая список занятий.
4. **Сверим прежний расчёт.** Проверим количества `0`, `1` и `3`, отказ для отрицательного числа и сохранность минут, часов и остатка.

Редакторская часть даёт небольшие наблюдения о том, что именно получает переменная цикла и сколько раз выполнится тело. В проектной части мы применим уже объяснённый механизм к существующей ветке, а не будем создавать второй расчёт или выдуманный список данных.

Итог подтвердим тремя количествами и повторной проверкой прежней формулы. Для нуля цикл должен пропустить вывод шагов, но остальная разрешённая ветка продолжит работу. Накопление значений и новый итог остаются следующей темой.
