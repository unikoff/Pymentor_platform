# Числа, операции и преобразование типов

Запишем понятное числовое правило, разделим время на часы и минуты, а текстовый ввод превратим в число.

**Темы:** `+` · `-` · `*` · `/` · `//` · `%` · `input()` · `int()` · `float()` · `str()`

## 00. От именованных значений к расчёту

1. **Точка старта:** в `main.py` уже есть стартовый экран и значения с понятными именами.
2. **Новый вопрос:** как получить итог для разного числа занятий, не подставляя готовый ответ?
3. **Результат:** локальная программа получает текстовый ввод, явно превращает запись в число и считает минуты, полные часы и остаток.

Сначала разберём вычисления на независимых примерах. Затем соберём их в правило для проекта и подключим клавиатурный ввод.

## 01. Операция вычисляет новое значение

Оператор задаёт действие над значениями. Выражение объединяет числа и оператор, а Python вычисляет его результат.

**Предскажем вывод:**

```python
print(7 + 2)
print(7 - 2)
print(7 * 2)
print(7 / 2)
```

```text
9
5
14
3.5
```

`+` складывает, `-` вычитает, `*` умножает, а `/` делит. Числовое выражение само по себе ничего не печатает. Передадим его в `print()`, чтобы увидеть результат, или присвоим результат переменной.

```python
rows = 3
seats_per_row = 8
total_seats = rows * seats_per_row
print(total_seats)
```

**Пошаговый разбор:**

1. `rows` получает значение `3`.
2. `seats_per_row` получает значение `8`.
3. Справа Python вычисляет `3 * 8` и связывает результат `24` с именем `total_seats`.
4. `print` показывает текущее значение `24`.

Выражение после знака `=` вычисляется первым. Затем результат связывается с именем слева. Присваивание сохраняет значение, но не выводит его.

Выражение `8 / 2` возвращает `float`, даже если делится без остатка. Результат записывается как `4.0`.

Формулу можно сравнить с коротким рецептом расчёта: значения говорят, сколько у нас рядов и мест в каждом, а `*` задаёт действие между ними. Имя `total_seats` хранит результат этого шага. Граница аналогии в том, что человек может догадаться о пропущенном шаге рецепта, а Python выполняет только явно записанные действия.

Python проверит, что операция допустима для значений, и вычислит её. Но он не знает, что мы хотели посчитать: число мест в одном ряду или все места в зале. Перед запуском сверим названия переменных, правило словами и единицу измерения результата.

Даже если синтаксис верен, формула может дать неправильный числовой результат. Python выполняет записанный порядок действий, но смысл мы проверяем сами: сверяем правило и единицы измерения.

## 02. Переведём правило словами в формулу

До записи формулы назовём, что измеряют входные значения и что нужно получить. Тогда можно проверить и смысл каждого действия, и его порядок.

В трёх коробках лежит по восемь книг, а ещё две книги стоят отдельно. Сначала найдём книги в коробках, затем прибавим оставшиеся.

```python
boxes = 3
books_per_box = 8
extra_books = 2
books_in_boxes = boxes * books_per_box
total_books = books_in_boxes + extra_books
```

Промежуточное имя `books_in_boxes` показывает первый результат. Время занятия рассчитывают похожим способом: количество умножают на длительность одного занятия, затем один запланированный перерыв прибавляют отдельно.

Проверим единицы: количество занятий умножается на минуты одного занятия, поэтому `study_minutes` уже измеряется в минутах. `break_minutes` тоже задан в минутах, и только поэтому эти значения можно складывать. Если сначала прибавить перерыв к длительности занятия, он добавится для каждого занятия, хотя в нашей модели перерыв один. Промежуточное имя помогает увидеть, что формула отражает именно выбранное правило.

Например, для трёх занятий по 40 минут получим 120 учебных минут. Один перерыв в 10 минут увеличит общий итог до 130. Из общего итога, а не из длительности одного занятия, выделим часы и остаток. Так видна роль каждой переменной: `study_minutes` описывает обучение, `break_minutes` один раз дополняет его, а `total_minutes` становится входом для деления.

**Как найти среднее трёх оценок?**

Без скобок:

```python
average = 4 + 5 + 6 / 3
```

Python сначала делит только `6`. Результат равен `11.0`, хотя код выполняется без ошибки.

С общей суммой:

```python
average = (4 + 5 + 6) / 3
```

Скобки собирают все три оценки до деления. Результат равен `5.0`.

Сначала выполняются скобки, затем умножение и деление, после них сложение и вычитание. При одинаковом приоритете Python вычисляет слева направо. Если делить нужно всю сумму, скобки должны охватывать каждое слагаемое. Python не знает, что автор имел в виду.

## 03. Переприсваивание использует прежнее значение

Знакомый счётчик можно изменить арифметическим выражением. Правая часть вычисляется до того, как Python запишет новое значение по тому же имени.

**Предскажем вывод:**

```python
pages_read = 4
pages_read = pages_read + 3
print(pages_read)
```

```text
7
```

Во второй строке правая часть даёт `4 + 3`. После этого имя `pages_read` связывается с числом `7`. Python не прибавляет к записи слева сам по себе и не хранит историю прошлых значений переменной.

Запись `pages_read = pages_read + 3` сначала вычисляет правую часть со старым значением, затем связывает имя с новым результатом. Знак `=` здесь не означает математическое равенство: это команда присваивания. Если старое значение ещё нужно, его можно заранее сохранить под другим именем. В нашем проекте мы выделим учебное время и общий итог отдельно.

Команды выполняются сверху вниз. Если первое значение счётчика поменяется с 4 на 10, вторая строка автоматически рассчитает 13, потому что читает текущее значение имени. Здесь не записан готовый ответ 7: записано правило «взять прежнее значение и добавить три». Это же свойство позволит пересчитать итог, когда изменятся входные данные.

## 04. Выберем вид деления для вопроса

Для неотрицательного количества минут можно спросить о дробных часах, только о полных часах или об остатке. Операция зависит от нужного ответа.

```python
minutes = 125
fractional_hours = minutes / 60
full_hours = minutes // 60
minutes_left = minutes % 60
```

- `125 / 60` даёт примерно `2.0833` часа.
- `125 // 60` находит `2` полных часа.
- `125 % 60` находит `5` оставшихся минут.

Для этих неотрицательных минут полные часы и остаток вместе восстанавливают исходное число: `125 = 2 * 60 + 5`.

Представим 125 жетонов, которые мы раскладываем в коробки по 60. Операция `//` показывает, сколько полных коробок собрано, а `%` сообщает, сколько жетонов осталось на столе. Эта аналогия работает для текущего расчёта неотрицательного времени; с отрицательными числами Python округляет результат `//` вниз, поэтому остаток нужно объяснять отдельно.

**Проверим границы:**

```python
print(0 // 60, 0 % 60)
print(59 // 60, 59 % 60)
print(60 // 60, 60 % 60)
print(61 // 60, 61 % 60)
```

```text
0 0
0 59
1 0
1 1
```

В каждой строке сначала указаны полные часы, затем остаток минут. До 60 минут полных часов нет. На границе 60 появляется первый полный час, а у 61 минуты остаётся одна. Для неотрицательных минут остаток всегда меньше 60.

Для любой неотрицательной суммы минут результаты связаны проверочным правилом: `total_minutes == full_hours * 60 + minutes_left`, а остаток находится от 0 до 59. Например, для 61 минуты получаем один час и одну минуту. Если вместо `%` вывести `/`, дробные часы вроде 1.016... уже ответят на другой вопрос и не заменят остаток. Поэтому выберем оператор по тому виду ответа, который хотим показать.

Обычный оператор `/` даёт `float`. Операторы `//` и `%` с целыми операндами дают целые значения.

Например, при 130 минутах `130 // 60` даст 2, а `130 % 60` даст 10. Проверим вместе: два полных часа содержат 120 минут, к ним прибавляем остаток 10, и снова получаем 130. Если остаток окажется равен 60 или больше, значит, мы неверно посчитали полные часы или выбрали другой делитель.

```python
print(type(8 / 2))
print(type(8 // 2))
print(type(8 % 2))
```

```text
<class 'float'>
<class 'int'>
<class 'int'>
```

Знак `%` означает остаток от деления, а не процент. Например, найти 25 процентов от 200 можно формулой `200 * 25 / 100`. В Python `//` в общем случае округляет результат вниз: `-7 // 3` равно `-3`. Это не просто удаление дробной части.

## 05. Ввод с клавиатуры сначала является текстом

Функция `input()` показывает приглашение и ждёт ввод до нажатия Enter. Она возвращает введённые символы как строку, но не сам Enter и не число, которое Python мог бы угадать по этим символам.

```python
raw_age = input("Возраст: ")
print(type(raw_age))
```

Если человек ввёл `18`, значение `raw_age` всё равно имеет тип `str`. Клавиатура передаёт текст. Python не угадывает, что его собираются использовать в арифметике.

- `int("18")` создаёт целое число из строки, которая записывает целое число.
- `float("2.5")` создаёт дробное число. Десятичную часть в числовой строке отделяет точка.
- `str(18)` создаёт строку из числа. Исходное значение при этом не меняется.

Преобразование возвращает новое значение. Например, после `age = int(raw_age)` имя `raw_age` продолжает хранить строку, а `age` связывается с целым числом.

Представим поле формы, в котором записано `"18"`. Получив строку, `input()` сохраняет её символы, а `int()` пытается прочитать их как целое число. Если внутри слова, функция не угадывает смысл и сообщает `ValueError`. Преобразование создаёт новое значение и не переписывает исходный текст.

Для количества занятий выберем `int()`, потому что считаем целое число занятий. Запись `"2.5"` представляет дробное число: `float("2.5")` её понимает, а `int("2.5")` сообщает `ValueError`, потому что это не запись целого значения. `float("18")` тоже может создать `18.0`, но дробное количество занятий нам не нужно. Выберем преобразование по смыслу данных, а не только по их внешнему виду.

На экране строка `"18"` и число `18` могут выглядеть одинаково, но строка не участвует в числовом умножении как количество. Поэтому отделим чтение символов от их трактовки: сохраним ввод в `raw_lessons`, затем результат преобразования в `lesson_count`. По этим именам можно понять, какое значение ещё текстовое, а какое уже готово к расчёту.

**Расположим действия так, чтобы прибавить один год к возрасту:**

```python
age_text = input("Возраст: ")
age = int(age_text)
next_age = age + 1
print(next_age)
```

Сначала `input()` возвращает строку. `int()` создаёт целое число, и только после этого можно прибавить `1`.

```python
print("2" + "1")
print(2 + 1)
```

```text
21
3
```

Знак `+` соединяет две строки, но не складывает строку и целое число. Если нужно добавить число в текст, сначала применим `str(value)`. Телефонный номер обычно остаётся текстом, потому что над ним не выполняют арифметику.

В первом примере обе части `+` имеют тип `str`, поэтому соединяются символы и получается `"21"`. Во втором обе части имеют тип `int`, поэтому вычисляется сумма `3`. Если числовое значение нужно присоединить к сообщению, сначала явно превратим его в текст. Такое преобразование меняет вид значения для дальнейшей операции, но не исправляет и не меняет исходную переменную.

## 06. Читаем причину ошибки по операции

Ошибка сообщает, какое действие не удалось. Найдём эту операцию и проверим типы, содержимое значения или делитель.

- `TypeError`: несовместимые типы, например `"18" + 1`.
- `ValueError`: неподходящее содержимое, например `int("восемнадцать")`.
- `ZeroDivisionError`: деление на ноль, например `10 / 0`.

`"72,5"` вызывает `ValueError`: операция преобразования подходит, но содержимое записано в неверном формате. `"18" + 1` вызывает `TypeError`: значения имеют несовместимые типы. При делении на ноль возникает `ZeroDivisionError`.

При чтении сообщения сначала найдём тип ошибки и строку, на которой она возникла. Затем сопоставим операцию с данными: для `TypeError` сравним типы, для `ValueError` проверим запись внутри строки, для `ZeroDivisionError` посмотрим на делитель. Исправим один источник проблемы и запустим пример снова. Так мы учимся читать причину, а не угадывать замену вслепую.

Все три примера останавливаются на своей операции: смешанное сложение, преобразование неподходящей записи или деление на ноль. Исправление должно соответствовать именно этой причине. Например, увеличение делителя не поможет преобразовать слово в число. В этой главе мы оставляем сообщение ошибки видимым; повторный ввод и проверку данных добавим после знакомства с условиями.

Не будем скрывать ошибку через `try`. Сначала проверим типы, затем содержимое текста и делитель. Прочитаем последнюю строку сообщения, исправим нужное значение или операцию и запустим пример снова.

## 07. Ввод платформы и ввод в программе

Одно вычисление может получить исходное значение разными способами. После получения и преобразования числа формула работает одинаково.

- При проверке на платформе переменные задания создаются заранее.
- В локальном `main.py` человек вводит значение через `input()`.

В редакторной задаче платформа заранее создаёт `raw_lessons`, поэтому мы не вызываем там `input()`. В локальном `main.py` этого имени ещё нет: `input()` получает строку с клавиатуры, и мы связываем её с `raw_lessons`. Источники разные, но оба значения пока текстовые.

В обеих версиях `int(raw_lessons)` создаёт целое `lesson_count`. Затем мы умножаем его на длительность занятия, один раз прибавляем `break_minutes` и применяем к общей сумме `//` и `%`. Платформа меняет переданные значения между проверками; локально мы вводим новое значение при каждом запуске.

## 08. Что мы будем делать в практике

Сначала применим формулу и проверим границы на меняющихся значениях платформы. Затем продолжим тот же локальный проект: сохраним стартовый экран и после него добавим расчёт учебного времени по вводу пользователя.

1. **Применим формулу в редакторе:** возьмём переданные платформой значения и получим время, полные часы и остаток без фиксированного ответа.
2. **Проверим границы часа:** заранее предскажем результат для 0, 59, 60 и 61 минуты и объясним переход через 60.
3. **Продолжим `main.py`:** сохраним стартовый экран, прочитаем строку `input()`, преобразуем её и подключим расчёт.
4. **Сверим несколько запусков:** сопоставим вводы 2, 3 и 0 с формулой, затем проверим в `main.py` один час через 59 минут занятия и минутный перерыв.
5. **Разберём причины ошибок:** на отдельных примерах различим несовместимые типы, неподходящий текст и деление на ноль.
6. **Сохраним результат:** вернём основные параметры, повторно запустим тот же проект, убедимся, что прежний экран остался, и сохраним правку в Git.

В редакторной задаче значения приходят от платформы, поэтому там мы не вызываем `input()`. В проекте мы читаем настоящую строку с клавиатуры и сохраняем её отдельно от числового результата `int()`. Эта разница позволяет использовать одну формулу при двух способах получения данных.

Один перерыв прибавляется после расчёта учебных минут. Поэтому ввод 0 при перерыве 10 даёт 10 минут, а ноль во всех итогах получится при нулевом количестве занятий и нулевом перерыве. Границы 0, 59, 60 и 61 минуты редакторная проверка пройдёт на меняющихся входах; в проекте отдельно проверим один реальный ввод на переходе через час. Условия, повторный запрос и обработчики ошибок появятся позже.

### Главное после занятия

- Операция вычисляет значение, которое можно вывести или сохранить под именем.
- Скобки помогают точно записать, какие части формулы нужно объединить.
- `/` даёт дробное деление, `//` полные единицы, `%` остаток.
- `input()` возвращает строку, а `int()` и `float()` создают числа.
- `TypeError`, `ValueError` и `ZeroDivisionError` сообщают о разных причинах.
