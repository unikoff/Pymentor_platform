## Место в маршруте

Занятие вводит две разные структуры по одной за раз. Tuple сохраняет фиксированный порядок пары; set оставляет только уникальные значения и не предоставляет позиций. Следующее занятие переносит tuple и set в маршрут изучения словаря.

## 00. Вступление

По паспорту list — знакомая опора, но фактическое освоение этого материала в текущей версии не подтверждено. Сначала коротко восстановим нужные свойства списка. Затем разберём tuple и дадим ученику самостоятельный шаг с парой и распаковкой. Только после него перейдём к set и закрепим его основные свойства до сравнения множеств.

1. **Точка старта:** порядок, позиции, повторы и изменение list; принадлежность как вопрос о наличии значения.
2. **Новый вопрос:** когда нужна упорядоченная пара с фиксированным составом, а когда — набор только уникальных значений?
3. **Результат:** ученик создаёт и распаковывает tuple-пару, исследует set на повторы и принадлежность, затем выбирает структуру по условию.

Tuple отвечает на требование сохранить порядок и состав пары. Set отвечает на требование убрать повторы и проверить наличие без обращения к позиции. Последовательное введение этих моделей даёт самостоятельную практику после tuple, до перехода к множествам, и ещё одну после знакомства с базовыми свойствами set.

## 01. Восстанавливаем свойства list

- Что и зачем объяснить: вернуть только предпосылки сравнения: порядок, повторы, позицию, принадлежность и изменение списка. Не повторять весь урок о list и его методах.
- Механизм и порядок: на коротком подготовленном списке прочитать элемент по позиции, проверить наличие значения и проследить одну знакомую операцию изменения. Уточнить разницу между изменением исходного списка и результатом операции, если пример на это опирается.
- Пример и типичная путаница: два одинаковых названия занимают две позиции; проверка принадлежности сообщает о наличии, но не о позиции. Не считать свойства list общими для set.
- Опора для повторного обращения: перед выбором структуры спросить, нужно ли сохранить порядок, повторы или позицию.
- Переход к следующему шагу: если порядок и фиксированный состав пары важны, сравнить list с tuple.

## 02. Tuple хранит фиксированный порядок

- Что и зачем объяснить: tuple сохраняет порядок и доступ по позиции, но его состав нельзя изменить операциями, которыми меняют list. Его назначение — зафиксировать последовательность значений, например пару с двумя известными ролями.
- Механизм и порядок: сопоставить list и tuple с одинаковой парой значений. Показать чтение позиций и объяснить, что tuple образует запятая; круглые скобки могут только группировать выражение. Для одного значения показать различие между скобками вокруг значения и записью с завершающей запятой.
- Пример и типичная путаница: запись в скобках без запятой остаётся исходным значением, а запятая задаёт одноэлементный tuple. На этом занятии не разбирать изменяемый объект внутри tuple: это дополнительное замечание о вложенных ссылках, его подробное объяснение отложить после занятия 17.
- Опора для повторного обращения: проверить, сколько элементов хранит пара, в каком порядке и является ли изменение состава требованием.
- Переход к следующему шагу: если два значения tuple имеют известный порядок, их можно связать с двумя именами через распаковку.

## 03. Пара и распаковка — самостоятельная остановка

- Что и зачем объяснить: распаковка связывает элементы пары с отдельными именами в их порядке. Для успешного шага число имён должно совпадать с числом элементов.
- Механизм и порядок: сначала прочитать два значения tuple по позиции, затем объяснить, какое значение попадёт в первое и второе имя. Вложенность не требуется.
- Пример и типичная путаница: использовать нейтральную пару из двух разных значений. Не путать позиционное соответствие с поиском по смыслу или автоматическим подбором имён.
- Опора для повторного обращения: перед распаковкой назвать число элементов и проверить такое же число имён, сохранив порядок.
- Самостоятельная остановка: после разобранного примера ученик самостоятельно создаёт или получает другую tuple-пару, распаковывает её в два имени и предсказывает результат. Наблюдаемый результат — имена содержат соответствующие значения в том же порядке; ученик объясняет сопоставление позиций.
- Переход к следующему шагу: после отдельного завершённого действия с упорядоченной парой поставить другой вопрос: как получить только уникальные значения, если индекс и исходный порядок не нужны.

## 04. Set: уникальность, принадлежность и отсутствие индекса

- Что и зачем объяснить: set хранит каждое уникальное значение не более одного раза, не обещает порядок и не поддерживает индексацию. Проверка принадлежности отвечает, входит ли значение в множество.
- Механизм и порядок: на подготовленном списке с повторами показать множество и сравнить составы. Уточнить, что повтор не создаёт вторую копию. Пустое множество задаётся через set(), потому что пустые фигурные скобки обозначают пустой словарь.
- Пример и типичная путаница: позиция в печатном представлении set не является договором порядка; у set нельзя запрашивать элемент по индексу. Для проверки состава использовать принадлежность или сравнение множеств, не расположение напечатанных элементов.
- Опора для повторного обращения: set — уникальность и принадлежность без позиции; tuple — упорядоченная пара с позициями.
- Самостоятельная остановка: после одного разобранного наблюдения ученик на других исходных значениях проверяет, какие значения останутся уникальными, отвечает на вопрос о принадлежности и объясняет, почему индекс здесь не подходит. Результат оценивается по множеству значений и проверкам членства, независимо от порядка вывода.
- Переход к следующему шагу: только после этой остановки перейти к изменению одного множества, а затем к операциям между двумя множествами.

## 05. Операции над одним множеством

- Что и зачем объяснить: add добавляет значение, remove удаляет присутствующее значение и сообщает об ошибке при отсутствии, discard допускает отсутствие удаляемого значения. Ученик выбирает операцию по исходному состоянию и нужному поведению.
- Механизм и порядок: сначала добавить новое и уже присутствующее значение; затем удалить существующее. Отдельно сравнить случай отсутствующего значения для remove и discard на изолированных примерах, чтобы ожидаемая ошибка не прерывала остальные шаги. Обработчик исключений не вводить.
- Пример и типичная путаница: повторное add не добавляет дубликат; remove и discard отличаются именно поведением при отсутствии. Не требовать определённого порядка отображения.
- Опора для повторного обращения: проверить, есть ли значение до удаления и должно ли отсутствие считаться ошибкой.
- Переход к следующему шагу: после операций над каждым множеством отдельно сравнить смысловые результаты для двух множеств.

## 06. Операции над двумя множествами

- Что и зачем объяснить: объединение включает значения обоих множеств, пересечение оставляет общие, разность первого и второго оставляет значения только первого. Показать операторные формы по смыслу: |, & и -.
- Механизм и порядок: взять два небольших множества, сначала проговорить ожидаемый смысл результата, затем применить соответствующую операцию. Проверять итог сравнением состава или принадлежностью конкретных значений.
- Пример и типичная путаница: разность зависит от направления: значения первого множества, которых нет во втором. Не сравнивать результаты как упорядоченные списки и не сортировать set ради повторяемого вывода.
- Опора для повторного обращения: назвать вопрос «все вместе», «общие» или «только из первого» до выбора операции; подтвердить состав и принадлежность, не порядок печати.
- Переход к следующему шагу: собрать критерии выбора tuple и set, а дополнительные детали оставить вне обязательного ядра.

## 07. Выбор структуры и дополнительные пояснения

- Что и зачем объяснить: сравнить tuple и set по назначению: tuple сохраняет порядок фиксированной пары, set хранит уникальные значения без индекса. После основной модели кратко рассмотреть count/index у tuple как подсчёт совпадений и позицию первого совпадения. Показать, что изменяемый list нельзя добавить как элемент set; объяснить ограничение без разбора устройства хеширования.
- Механизм и порядок: сначала самостоятельное применение основной модели, затем краткие дополнительные сведения. Ученик не должен зависеть от count/index или ограничений элементов set, чтобы выполнить практику и достичь B.
- Пример и типичная путаница: index у tuple не означает, что у set появляется позиция. Необязательное пояснение о tuple: внешний состав зафиксирован, но изменяемый объект внутри него может меняться; полное исследование этой вложенной ссылки отложить до занятия после 17.
- Опора для повторного обращения: для выбора назвать требование к порядку, повторам и индексации; дополнительные операции не заменяют основную модель коллекции.
- Переход к следующему шагу: применить выбор на изменённых данных и объединить подтверждённые результаты.

## 08. Что мы будем делать в практике

**Формат и исходная опора:** короткие scripts на платформе с видимыми или описанными исходными значениями. Начинаем с восстановленных свойств list. После объяснения tuple и распаковки ученик выполняет самостоятельную остановку до введения set; после объяснения уникальности, принадлежности и отсутствия индекса — вторую остановку до операций над множествами. Итоговая практика переносит оба критерия на новые данные.

1. **Создать и распаковать пару:** на других исходных значениях получить упорядоченную пару и самостоятельно связать её элементы с двумя именами. Опора — блоки 02–03. Результат — значения соответствуют позициям, ученик может объяснить порядок и распознать одноэлементный tuple по запятой.
2. **Проверить базовую модель set:** получить множество из списка с повторами, проверить уникальность и принадлежность, объяснить отсутствие индекса. Опора — блок 04. Результат — верный уникальный состав и вывод о членстве; точное совпадение печатного порядка не проверяется.
3. **Применить операции между множествами:** на двух новых наборах выбрать объединение, пересечение или направленную разность. Опора — блоки 05–06. Результат — ученик выбирает операцию по вопросу и подтверждает состав сравнением множеств или принадлежностью; сортировка и порядок печати не служат критерием.
4. **Выбрать структуру для изменённого условия:** решить, нужно ли сохранить упорядоченную пару или оставить уникальные значения, выбрать tuple либо set и подтвердить выбор небольшим опытом. Опора — блок 07. Результат — ученик объясняет выбор через порядок, повторы, фиксированный состав и отсутствие индекса у set.

Две самостоятельные остановки дают первый результат на tuple до перехода к set и закрепляют основу set до сравнения двух множеств. Итоговые действия проверяют перенос на изменённые данные, а не копирование разобранного случая. Накопленные результаты подтверждают B: ученик создаёт и распаковывает упорядоченную пару, применяет set по требованиям уникальности и обосновывает выбор структуры. Проект не меняется.
