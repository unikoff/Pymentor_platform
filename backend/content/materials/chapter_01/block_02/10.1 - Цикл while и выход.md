## Точка B: проверяемый результат занятия

Ученик **самостоятельно пишет конечный повтор**, показывает последовательность значений перед проверкой условия, объясняет ноль/один/несколько проходов и доказывает достижимость остановки на каждом пути. В цикле `while True` он располагает `break` по условию, а при `continue` гарантирует обновление состояния до нового прохода. Результат проверяется на подготовленных значениях и отличающихся граничных случаях, без живого ввода.

## 00. Вступление

Для `for` список сам определял количество шагов. Теперь задача может требовать: «Повторяй, пока значение меньше границы» или «Читай подготовленные сигналы, пока не встретишь stop». Приходится отвечать за остановку самостоятельно.

1. **Точка старта:** опираемся на планируемое владение `if`, сравнением, переменными, `for`, `break`/`continue` из занятий 6–10; фактическую готовность проверяем перед выдачей.
2. **Новый вопрос:** кто и когда перепроверяет условие, что меняется между проверками и что помешает бесконечному повтору?
3. **Результат:** написать конечный `while`, затем `while True` с проверяемым выходом, включая путь через `continue`.

Переход: сначала проследим маленький числовой пример с условием до тела; после этого добавим выход по `break` и обработку списка подготовленных сигналов. Для каждого нового механизма сначала будет независимая трасса, потом действие ученика.

## Последовательность теории

1. Условие проверяется до тела, поэтому возможны ноль проходов.
2. Четыре вопроса перед запуском: начало, продолжение, изменение и остановка.
3. Проход по списку с проверкой границы до чтения.
4. While True требует достижимого break.
5. Continue разбирается отдельно: прогресс должен произойти до нового прохода. Подозрительный цикл сначала исследуется без запуска.

## Практика

- Конечный счётчик с поддержкой.
- Проход по списку по указателю.
- Разбор next/skip/stop с безопасным продвижением.
- Обязательный обратный отсчёт с пустого редактора: ученик выбирает состояние, условие и изменение.

## Приёмка и границы

Ноль проходов, начало ниже предела, один и несколько проходов, граница ноль; объяснение остановки входит в результат.

Подсказки служат восстановлению затруднившего шага и открываются после собственной попытки. В самостоятельных работах исходные данные и договор результата заданы явно; конкретный алгоритм и расположение состояний не подставляются в стартовый код. Новые конструкции языка вне указанной опоры не требуются.
