## 00. Вступление

Ученик уже встречал отдельные значения и коллекции; теперь нужно вывести каждое значение списка, не переписывая `print` для каждой позиции. Начать с `[10, 30, 50]` и вопроса «Как вывести всё, если завтра элементов станет четыре?». Сначала объяснить один повторяемый блок, не начинать с индексов или `range`.

1. **Точка старта:** подготовленный список с различимыми значениями и знакомое чтение одного элемента.
2. **Новый вопрос:** как последовательно получить очередное значение и выполнить для него одно действие?
3. **Результат:** script с простым конечным обходом, где можно назвать текущий элемент, значение переменной цикла и наблюдаемый вывод.

Пояснить связь: ученик прослеживает прямой проход по списку, **сам пишет** такой же цикл на других данных, затем переносит механизм на знакомую строку. Далее разбирает `range` для известного числа повторений, применяет числа как позиции, после этого выбирает обход словаря и читает список записей. Накопление итогов остаётся за границами занятия. В MAIN у ключевых переходов запланировать содержательные трассы/визуалы и короткие прогнозы «что будет в переменной / что напечатается»; вставка должна помогать освоить новый механизм, а не просто разбивать текст.

## 01. Как выполняется один цикл for

- **Механизм до первого применения.** На подготовленном `[10, 30, 50]` разобрать `for item in values:`: `for` начинает проход, имя `item` **на каждом проходе получает одно очередное значение**, `in values` задаёт источник. Двоеточие завершает заголовок; дополнительный одинаковый отступ отмечает строки тела. Объясняющий пример показывает `print(item)` с отступом и `print("Готово")` без него. Первая команда исполняется трижды, вторая — только после завершения цикла и ровно один раз.
- **Трасса наглядно.** Проход 1: `item = 10` → вывод `10`; проход 2: `item = 30` → `30`; проход 3: `item = 50` → `50`; затем вне тела `Готово`. Визуал выделяет текущую строку и элемент. До запуска изменённого `[4, 9]` ученик предсказывает две строки значений и одну строку завершения; проверяет прогноз на выводе.
- **Пустота и имя.** При `values = []` тело ни разу не выполняется, но команда вне тела по-прежнему исполняется. Если до цикла `item` не существовало, пустой `for` не создаёт это имя. После непустого цикла оно может хранить последний элемент, однако чтение его после **пустого** источника приведёт к ошибке (или к устаревшему значению, если имя уже существовало); не использовать его как гарантированный результат цикла. Имя не является индексом автоматически.
- **Опора и переход.** Четыре вопроса для повторения: откуда берём → что попало в имя → что происходит с отступом → что выполняется после блока. После прогноза по пустому/непустому источнику дать самостоятельно написать простой цикл; `range` ещё не нужен.

## 02. Прямой обход списка и символов строки

- **Первое самостоятельное написание.** После разобранного примера ученик получает **другие** значения `[7, 7, 2]`, выбирает имя переменной и сам пишет заголовок `for`, отступ и печать каждого значения, затем добавляет одно сообщение **после** цикла. Не давать готовый цикл, где осталось изменить надпись. Прогноз для трёх элементов с повтором отличает обход каждого вхождения от выбора уникальных значений. На `[]` в теле нет вывода, на `[6]` он один, строка после цикла остаётся одной в обоих случаях.
- **После списка — строка.** Напомнить, что уже знакомая строка состоит из символов в порядке их следования. В отдельном объясняющем примере разобрать `for letter in "кот":` и печать `letter`: `"к"`, `"о"`, `"т"` поступают по одному символу. Пустая строка `""` даёт ноль проходов; повторы символов остаются отдельными проходами. Только после демонстрации ученик **сам составляет** цикл по другой короткой строке и прогнозирует результат для пустой. Индексы строк здесь не нужны.
- **Опора и переход.** Для обоих источников: «текущий элемент → имя → действие → вывод». Два одинаковых значения означают два исполнения тела. Ученик уже пишет прямой `for` по новым данным; затем вводится `range` как иной источник чисел, пока без обращения к списку по позициям.

## 03. range: повторяем известное число раз

- **Зачем:** иногда нужно выполнить одно действие заданное число раз без готового списка значений. `range` задаёт последовательность целых чисел, которую может обходить `for`; переменная цикла получает очередное **число**, пока ещё не индекс другого источника. Не называть `range` готовым списком.
- **Механизм до примера.** Сначала одна граница: `range(4)` даёт `0, 1, 2, 3`, **не включая** `stop=4`; `range(0)` не даёт ни одного числа. Затем форма с началом: `range(2, 5)` даёт `2, 3, 4`, `range(3, 3)` — пуст. Во всех случаях по умолчанию шаг +1. Отрицательный шаг и его запись здесь не нужны.
- **Прогноз → наблюдение → собственный код.** На объясняющем `range(3)` и `print("Сигнал")` показать: переменная получает `0, 1, 2`, но на экран трижды выходит **одинаковая** строка, поскольку тело не использует число. На новых границах ученик прежде запуска перечисляет числа, затем пишет свой `for` на пять одинаковых сообщений; проверяет отдельно `range(0)` и `range(4, 6)`. Локальный критерий — число строк и отсутствие исполнения при пустом диапазоне, без счётчика.
- **Опора и переход.** Для `range` записать start, stop, получаемые числа и число проходов. Если start не меньше stop при шаге +1, тело не выполнится. Лишь после самостоятельного предсказания числового обхода показать, что эти числа могут стать позициями списка.

## 04. От числовых шагов к позициям

- Что и зачем объяснить: индекс нужен, когда задача спрашивает о позиции или требуется получить элемент через позицию. Если достаточно обработать все значения, прямой обход остаётся проще.
- Механизм и порядок: вернуться к списку со значениями 10, 30, 50. Отдельно проследить прямой проход, где переменная цикла равна текущему значению, и проход по позициям, где range даёт 0, 1, 2. Связать каждую позицию с соответствующим элементом по знакомому чтению списка.
- Пример и типичная путаница: 10, 30, 50 — данные; 0, 1, 2 — позиции. Позиция не является значением, порядковым номером для пользователя или постоянным id. Значения могут повторяться, а позиции всё равно различаются.
- Опора для повторного обращения: спросить, нужен ли элемент или его позиция. Для элемента выбрать прямой обход; range применять к позициям только при явной потребности. Не менять размер исходного списка во время обхода.
- Переход к следующему шагу: после уверенного простого for и понимания range перейти к отдельному источнику — словарю и его парам.

## 05. Пары словаря и распаковка

- Что и зачем объяснить: у словаря можно обходить ключи, значения или пары; форма выбирается по тому, что требуется узнать. Пара нужна для одновременной связи имени поля с его значением.
- Механизм и порядок: сначала напомнить, что прямой проход по словарю даёт ключи. После этого показать items() как источник пар ключ–значение и распаковку каждой пары в две переменные цикла. Объяснить используемый здесь метод до его применения; связать распаковку со знакомой парой и равным числом элементов и переменных.
- Пример и типичная путаница: на одной подготовленной записи сопоставить ключ и соответствующее значение. Не предполагать, что прямой проход даёт значения или пары; не путать отдельную пару поля со всей вложенной записью.
- Опора для повторного обращения: для имён полей выбрать ключи, для значений — представление значений, для связи «ключ–значение» — items() и распаковку. Не вводить другие методы коллекций и не менять словарь во время обхода.
- Переход к практике: сначала применить уверенно освоенный простой цикл и range; только после этого перейти к самостоятельному чтению словарных пар и записей.

## 06. Что мы будем делать в практике

**Формат и исходная опора:** короткие scripts в редакторе платформы; начинаем с подготовленного списка значений 10, 30, 50. Используем прямой for и видимые исходные данные. Затем изучаемый range применяется к известному числу шагов, а после объяснения — к позициям. input() не нужен и недоступен в исполнителе.

Общий результат — самостоятельный script, в котором ученик прослеживает текущий элемент, значение переменной цикла и вывод, отличает данные от позиций и после освоения простой формы выбирает обход пар словаря.

1. **Самостоятельно обойти короткий список:** на подготовленных значениях 10, 30, 50 предсказать проходы и самостоятельно выбрать одно действие для каждого текущего элемента. Затем проследить пустой список, один элемент и повторы. Критерий шага: значения и вывод указаны в правильном порядке, число выполнений тела совпадает с числом элементов, после цикла действие выполняется один раз. Опора — блоки 01–02 и пройденный навык чтения списка. Стартовый список не требует нового метода; перед выдачей подтвердить базовую опору занятия 6.1.
2. **Понять range на числе шагов:** по заданному количеству шагов перечислить значения range, объяснить число проходов и исключённую границу stop, включая ноль. Критерий шага: ученик не считает stop элементом и верно называет число выполнений. Опора — блок 03; range объяснён непосредственно перед практикой.
3. **Применить range к позициям:** после предыдущего шага сопоставить позиции 0, 1, 2 с данными 10, 30, 50 и сравнить этот способ с прямым обходом. Критерий шага: ученик называет отдельно позицию и значение, выбирает прямой обход, если индекс не нужен. Опора — блок 04 и чтение списка по позиции; действие зависит от подтверждения занятия 6.1.
4. **Отдельно обойти пары словаря:** после уверенного простого for получить на подготовленной записи ключи, значения или пары; самостоятельно выбрать распаковку только для пар. Критерий шага: метод объяснён до применения, ключ связан со своим значением, источник не изменён. Опора — блок 05 и материалы о dict/items/парах из занятий 7.2–8; без подтверждения этой опоры действие не принимать.
5. **Перенести обход на список записей:** на подготовленных нейтральных записях пройти внешний список напрямую и получить нужное поле текущей записи. Критерий шага: результат соответствует порядку и числу записей, пустой список не запускает тело, данные не изменяются. Опора — пройденный простой for, словарные пары и вложенные записи занятия 8.1; действие зависит от выполнения его практики учеником.

Пункты идут от одного прямого обхода к числовым шагам, затем к позициям, парам и вложенным данным. Трассировка «текущий элемент → переменная цикла → вывод» остаётся краткой опорой для действий, а не отдельным интерактивом. Условия карточек, точные данные, ответы и интерфейс разрабатываются на этапе 3.

**Итоговый критерий всей практики:** на новом коротком источнике ученик самостоятельно прослеживает прямой for, объясняет число шагов и границу range, отличает 10, 30, 50 от позиций 0, 1, 2 и, при подтверждённой опоре, проходит словарные пары и записи. Итог не требует накопителя, счётчика или результата занятия 9.1.
