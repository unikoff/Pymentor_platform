Две опоры для визуализации: «ряд клеток с буквами» помогает различать символы и индексы, а «метки на границах между клетками» — понять, где останавливается срез. Не приравнивать символ Python к любому видимому человеку сложному знаку.

## 01. Текст, пустая строка и пробел

- **Зачем и как:** строка — текстовое значение; запись `"кот"` означает три буквы, а парные кавычки задают его границы в коде. Проговаривать отличие `pet` (имя, заданное раньше) от `"pet"` (четыре буквы), и что `print("кот")` показывает слово **без кавычек**. Двойные и одинарные кавычки равноправны, если открывающая и закрывающая согласованы. Перед примерами с новым текстом напомнить, что записывают код в поле редактора и смотрят результат ниже после запуска; новых команд запуска нет.
- **Независимое наблюдение:** сопоставить `print("чай")` и `print(" чай")`: у второй строки перед первой буквой есть пробел. Затем `""` (нет символов) и `" "` (один пробел) показать как две разные записи; их количественное различие подтвердим в разделе 03, а не требуем определить невидимое на глаз. Специальная запись `"\n"` обозначает перенос строки внутри текста; два знака `\` и `n` в исходном коде описывают один управляющий символ. Кавычку внутри текста показать на простом варианте с другой парой внешних кавычек, например `'Слово "да"'`, без обязательного изучения обратной косой черты.
- **Первая попытка:** дать пару строк вывода с одинаковым словом, но разным количеством пробелов; ученик до запуска отмечает, где изменится расположение текста, затем сам редактирует литерал, чтобы убрать пробел. Различающий вопрос: `""` и `" "` дадут одинаковую длину или нет? Ответ подтвердить лишь после ввода `len`.
- **Типичная ошибка / опора:** ожидать, что кавычки или внешние пробелы не имеют значения. Опора для возврата: «кавычки ограничивают строку; всё между ними, в том числе пробел и перевод строки, принадлежит тексту». Переход: части текста определены — теперь их нужно соединять.

## 02. Соединение и повторение строк

- **Зачем и как:** `+` между строками ставит их друг за другом без добавочных символов. Пройти слева направо независимый пример `"Добро" + " утро"` → `"Добро утро"`, затем сравнить `"Добро" + "утро"` → `"Доброутро"`. Отдельный пробел `" "` можно прибавить между двумя именами, а полученную строку сохранить обычным присваиванием из 1.1. Символ `*` рядом со строкой и целым числом означает повторение: `"-" * 3` → `"---"`, `"-" * 0` → пустой текст. Нуль полезен как различающий случай, но арифметику чисел сейчас не объясняем.
- **Независимое наблюдение:** собрать короткий заголовок из двух частей и повторённой черты, сначала предсказать видимый результат, затем вывести с помощью `print`. Если строки содержат `"\n"`, перенос оказывается только там, где его записали; `+` сам не создаёт ни новой строки, ни пробела. Отдельно объяснить: `"3"` — строка, `3` — число повторов; нельзя трактовать `"-" * "3"` как корректное повторение.
- **Первая попытка:** ученик получает `left = "Скоро"`, `right = "встреча"`; выбирает разделитель, сам записывает объединение, прогнозирует вывод и проверяет его. Затем без готовой строки повторения составляет линию из двух одинаковых знаков. Критерий: именно один пробел между словами и ровно два знака в линии.
- **Типичная ошибка / опора:** ожидание автоматического пробела или попытка передать число в кавычках для повтора. Вернуться к правилу: «`+` соединяет содержимое без изменений, `*` повторяет строку целое число раз». Переход: после сборки сообщения можно измерить **количество** символов, а не оценивать его по виду.

## 03. Длина — количество элементов

- **Зачем и как:** `len` — готовый инструмент Python для ответа «сколько элементов в строке?». Показать запись `len("мир!")` по частям: имя инструмента `len`, круглые скобки, строка внутри; результат — число `4`. Через уже знакомый `print(len("мир!"))` его можно увидеть в редакторе. Это **использование одной готовой функции**, пока без общей темы функций и аргументов. Для имени, которому присвоена строка, форма та же: `len(message)`; скобки здесь круглые, квадратные понадобятся позже для позиции.
- **Независимое наблюдение:** на схеме отдельных клеток разложить `"кот кот"`: три буквы, пробел, ещё три буквы — длина `7`. Сравнить `len("")` → `0`, `len(" ")` → `1`, `len("\n")` → `1`. Сначала подсчёт ученика, затем проверка выводом. Отдельно показать, что число символов не равно номеру позиции последнего символа: нумерацию позиций введём в 04. Для примеров использовать простые буквы; Unicode может содержать сложные видимые знаки из нескольких кодовых точек, поэтому общее обещание «любой видимый значок равен 1» недопустимо.
- **Первая попытка:** ученик получает `text = "дом!"`, сам до запуска подсчитывает длину и добавляет вывод через `print(len(text))`; затем меняет значение на слово с пробелом и заново предсказывает число. Критерий: учитывает невидимый пробел и не считает кавычки.
- **Типичная ошибка / опора:** пропустить пробел, ввести `len[text]` или принять результат `len` за индекс. Опора: «`len(строка)` возвращает количество; `print(...)` показывает его; считаем все элементы текста». Переход: число получено — осталось понять, по какому **номеру** читать конкретную букву.

## 04. Позиции и индекс

- **Зачем и как:** чтобы прочитать одну букву, у строки есть **индекс** — номер её места. Нарисовать четыре клетки `м | а | м | а` с подписями `0 | 1 | 2 | 3` под буквами. Длина этой строки — `4`, но последняя существующая позиция — `3`: это разные вопросы, «сколько?» и «где?». Сначала ученик указывает клетку по номеру **на рисунке**, затем видит запись `word = "мама"`, `word[2]`: квадратные скобки после имени означают «возьми элемент на месте 2», результат — строка `"м"` из одного символа. Никаких методов или вызовов функций здесь нет.
- **Независимое наблюдение:** сравнить `word[1]` и `word[3]`: обе буквы выглядят одинаково, но места различны. После объяснения обычной нумерации показать `word[-1]` как удобное чтение **последнего** символа без предварительного вычисления номера; отрицательные позиции целиком и арифметику не разворачивать. На короткой строке отдельно указать допустимые номера: от `0` до предпоследнего/последнего в зависимости от длины, для четырёх клеток — `0…3`. `word[4]` выдаёт `IndexError`, потому что четвёртой позиции с номером `4` нет; для пустой строки нет ни одной допустимой позиции. Разбор `try/except` не нужен: это пример того, чего не писать, а не упражнение на обработку исключения.
- **Первая попытка:** на новой строке `fruit = "какао"` ученик сам подписывает номера, до запуска выбирает символ в середине и последний через `[-1]`, записывает обращения в `print` и сверяет вывод. Затем объясняет без запуска, почему `fruit[5]` недопустим. Критерий: выбирает букву **по месту**, не по поиску похожей буквы, а граничную ошибку распознаёт по количеству клеток.
- **Типичная ошибка / опора:** ответить `len(word)` вместо номера последней клетки или начинать нумерацию с `1`. Опора: «сначала выпиши клетки с индексами от нуля; `[номер]` берёт один существующий символ». Переход: для целого слова или нескольких соседних букв потребуется отметить две границы.

## 05. Срез и неизменяемость строки

- **Зачем и как:** индекс `[2]` выбирает ровно один символ; **срез** `[начало:стоп]` выбирает подряд идущую часть. Нарисовать над теми же четырьмя клетками `м | а | м | а` **пять разделительных черт** перед первой буквой, между ними и после последней. Показать запись `word[1:3]` и чтение: начинаем с места `1` (`а`), продолжаем до границы `3`, **не берём** символ под номером `3`. Получаем `"ам"`. Границы среза — места начала и остановки; для начала использовать только два явно написанных неотрицательных числа, без сокращённой записи и шага.
- **Независимое наблюдение:** `word[2:2]` → пустая строка: остановка совпала с началом; `word[2:40]` → `"ма"`: срез берёт доступную часть до конца и не «падает» из-за слишком дальней правой границы. Противопоставить `word[40]`: отдельный **индекс** вне строки вызывает ошибку. Показать также: срез создаёт **другое строковое значение**, например `part = word[1:3]`; проверка `print(word)` после этого показывает прежнее слово. Присваивание вида `word[0] = "о"` нельзя использовать: символ по индексу не заменяется. Если нужен изменённый текст, собрать и сохранить **новое** значение из среза и дополнительной строки, воспользовавшись `+` из 02. Понятие «неизменяемость» назвать уже после наблюдения, без обсуждения памяти и объектов Python.
- **Первая попытка:** дать другую строку `label = "лампа"` и схему из пяти клеток. Ученик сначала на рисунке отмечает две границы для букв с номерами `1` и `2`, затем самостоятельно записывает срез, предсказывает результат и сверяет через `print`; вторым запуском делает пустой срез с одинаковыми границами. Критерий: в первом случае получены ровно два запрошенных символа, во втором — пустая строка, а `label` не меняется.
- **Типичная ошибка / опора:** включить букву с номером правой границы, ожидать ошибку от широкой границы или пытаться изменить исходный текст через `[индекс] = ...`. Опора: «`[номер]` — один символ, `[начало:стоп]` — от начала до, но **не включая** стоп; чтобы получить другой текст, создай и присвой новое значение». Переход к практике: теперь можно соединить части, измерить готовый текст и выбрать из него нужный фрагмент самостоятельно.

## 06. Что мы будем делать в практике

**Формат и исходная опора:** несколько коротких самостоятельных программ (`script`) в **редакторе платформы**: ученик набирает код, запускает кнопкой редактора, читает вывод и сравнивает его с ожидаемым. Для каждой независимой части даны только нужные исходные строки и числа; файлы и терминал не нужны, результат предыдущего запуска не сохраняется автоматически. Из урока 1.1 планируется умение прочитать присваивание и `print`; перед первой частью проверить эту опору. Все остальные операции заранее объяснены в 01–05. Технические исходные данные можно дать готовыми, но операции, определяющие B, ученик пишет сам.

1. **Собрать и измерить своё сообщение (сначала конструирование).** Вход: отдельно заданы `heading = "Афиша"`, `topic = "кино"`, `line = "="`; формат вывода словами — первая строка «Афиша кино», вторая строка из трёх `=`. Объект: новая переменная с сообщением, исходные значения не менять. Опора: кавычки и перенос из 01, `+`/`*` из 02, форма `len(...)` из 03. Самостоятельно выбрать место пробела и переноса, записать объединение и повторение (без готового выражения), сначала назвать ожидаемый текст и длину **всей строки с переносом**, затем вывести текст и число. Локальный критерий: пробел ровно один, перевод строки ровно один, черта ровно из трёх знаков; `len` совпадает с посчитанными символами, включая пробел и перенос. Различающий случай: заменить `topic` на пустую строку и объяснить, что автоматического удаления разделителей не происходит; дополнительного условия `if` не писать. Для первого знакомства допустимо сначала проверить только однострочную форму, затем добавить знакомый уже разобранный `"\n"`.
2. **Прочитать отдельный символ и часть по границам (следом выбор позиций).** Вход: независимая строка `name = "банан"` и задание «получи букву на позиции `2`, последнюю букву, фрагмент с позиций `1`, `2`, `3`». Объект: исходное `name`; сохранять новую строку можно под отдельным именем. Опора: схема индексов 04 и черты среза 05; ученик сам подписывает `0…4`, записывает обращения в квадратных скобках, выбирает правую границу, до запуска предсказывает вывод и сверяет. Локальный критерий: взят именно третий по счёту символ, последняя буква читается через `[-1]`, фрагмент содержит три буквы и **не** содержит позицию правой границы. Различающие случаи — отдельно получить пустой срез одинаковыми границами и срез с правой границей `50`: первый результат пустой, второй заканчивается на конце имеющегося слова; отдельная попытка `name[5]` обсуждается **без запуска** как выход за границу и не прерывает выполнение остальных шагов.
3. **Создать изменённый текст без изменения исходника (самостоятельное соединение).** Вход: отдельно заданы `source = "сыр"` и цель получить `"суп"`, оставив `source` прежним. Объект: новая переменная, которая содержит нужный результат. Опора: соединение 02, выбор фрагмента 05, различие имени и значения из планируемой 1.1. Ученик самостоятельно выбирает сохраняемую часть исходной строки и добавляемый текст, пишет **новое присваивание** и вывод обоих имён. Локальный критерий: новое значение равно требуемому слову, старое по-прежнему равно `"сыр"`; `source[0] = ...` не используется. Различающий вопрос: почему запись через индекс была бы ошибкой, даже если нужная буква находится на известном месте?
4. **Короткий перенос без готового шаблона решения.** На другом слове `"тесто"` ученик самостоятельно составляет схему индексов и без подсказки определяет длину, последний символ, срез для букв с позициями `1…3` и срез с правой границей далеко за концом. Затем объясняет различие между допустимым индексом и слишком широким срезом; при желании проверяет предсказания отдельными `print`. Критерий: граница остановки исключена, индекс `len(text)` не предлагается для получения последнего символа, широкий срез не объявляется ошибкой. Для пустой строки можно спросить только `len("")` и пустой срез, **не** задавая чтения несуществующего символа.

Логическая связка практики для MAIN (вторая группа `LinkedNotes`): **собрал сообщение → получил нужный видимый текст и длину; отметил позиции → правильно выбрал символ и фрагмент; составил новое значение → сохранил исходную строку; сменил данные → перенёс правило без готовой записи**. После этих шагов B наблюдаема по коду, выводу и объяснению различающего случая, а не по простому запуску готового примера. Примеры теории используют другие слова и сюжеты; в проверке не требовать новых методов, условий или обработки исключений.

**Итоговый критерий практики:** ученик самостоятельно вводит `+`, `*`, `len(...)`, `[индекс]`, `[начало:стоп]` на новых данных; видит ожидаемые строки, числа и фрагменты, объясняет пробел/перенос, отличие количества от позиции, исключение правой границы, безопасный широкий срез и неизменность исходного значения. Разрешена сверка с опорами 01–05, но готовые выражения к итоговым данным в теории не даются.
