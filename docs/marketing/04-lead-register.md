# Обезличенный журнал лидов и оплат

Этот файл — исходный ручной журнал, а не CRM и не подтверждение банковской операции. Не записывать имена, телефоны, адреса и переписку. Для каждого реального обращения использовать нейтральный ID, не публиковать контактную информацию.

Для новых записей добавить дату и время обращения, ID, признак «тест / коммерческое», продукт, источник и основание (например, сообщил клиент / UTM / неизвестно), стадию, цель и возражение своими словами без персональных данных, дату и сумму фактически подтверждённой оплаты, получателя (наставник / платформа / неизвестен), исход и дату следующего действия. У одного клиента может быть несколько касаний: не дублировать выручку. Оплаты наставнику и подписки платформе считать отдельно. [Протокол сверки](37-lead-measurement-protocol-2026-11-04.md).

Для ежедневного контроля бюджета фиксировать отдельно дату, начальный баланс, расход за день и накопленный расход с точной даты начала теста, обозначение с НДС/без НДС, оставшийся ориентир и принятое решение. Отсутствующее значение — «неизвестно», не ноль. Метрика с условной ценностью цели и реклама не являются платёжным реестром.
