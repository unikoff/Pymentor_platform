# Работа с методичками Stage 1–5

Применяй [общий стандарт](STAGE_COMMON_STANDARD.md) и маршрут выбранного Stage из [START](START.md). Один запуск — один Stage; для Stage 2/3 один пользовательский форк выполняет ровно одно занятие. Для Stage 2/3 следующие занятия и этапы запускаются отдельно. Stage 5 одним чатом последовательно проходит весь назначенный диапазон внутри главы. C/B/F, P1–P4 и M1–M5 сохраняются как внутренние шаги и отдельные методички.

Читай текущий шаг и нужные источники, сохраняя имеющиеся результаты и чужие изменения. Не создавай отдельного агента, отчёт или подтверждение на каждый шаг. Документируй только решения, необходимые следующему шагу, фактические проверки и незавершённое. Сквозная цепочка разных Stage и прежняя диспетчеризация отдельных уроков не используются; это не запрет полного назначенного диапазона Stage 5.
