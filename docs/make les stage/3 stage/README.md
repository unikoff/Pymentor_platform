# Stage 3: создание занятия

Один форк пользователя выполняет Stage 3 одного конкретного занятия. Очереди уроков внутри форка нет. Используй существующий принятый план Stage 2, паспорт, конкретные источники предпосылок и текущие артефакты; отдельное досье передачи не создаётся. При продолжении не генерируй заново уже готовые части.

Последовательные методички сохраняются отдельно:

1. [M1 — теория](01_THEORY_DRAFT.md): [skill теории](../../../.agents/skills/pymentor-lesson-theory/SKILL.md), объяснения и независимые примеры до самостоятельного применения.
2. [M2 — практика](02_PRACTICE_DRAFT.md): [skill практики](../../../.agents/skills/pymentor-lesson-practice/SKILL.md), понятные поля карточек, пошаговые разборы и проверки.
3. [M3 — редактура](03_CONTENT_EDIT.md): связность теории и практики, полнота и отсутствие повторов.
4. [M4 — визуалы и интерактивы](04_VISUAL_INTERACTIVE.md): учебная функция, состояния, доступность и исправление при создании.
5. [M5 — приёмка](05_LESSON_ACCEPTANCE.md): предметная проверка, четыре фактических технических уровня и полный осмотр страницы.

[STAGE_FLOW.md](STAGE_FLOW.md) определяет общий порядок, локальный браузер и итоговую проверку. При недоступном обязательном наблюдении укажи `НЕ ПРОВЕРЕНО`; сборка не подтверждает фактическую выдачу или страницу. Проверки относятся к итоговой версии своего занятия; не жди остальных форков. Чужой результат сборки применим только при доказанной актуальности версии и зависимостей. Stage 4 и Stage 5 не запускаются автоматически.
