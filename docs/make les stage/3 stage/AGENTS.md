# Stage 3: локальные указания

Stage 3 запускается в пользовательском форке для одного конкретного занятия. [STAGE_FLOW.md](STAGE_FLOW.md) задаёт порядок [M1](01_THEORY_DRAFT.md) → [M2](02_PRACTICE_DRAFT.md) → [M3](03_CONTENT_EDIT.md) → [M4](04_VISUAL_INTERACTIVE.md) → [M5](05_LESSON_ACCEPTANCE.md); каждый шаг сохраняет свои предметные критерии. Указанный пользователем ограниченный шаг имеет приоритет. Продолжай с фактически незавершённого своего урока, сохраняя готовые части. Не бери другие уроки из истории форка и не создавай новые чаты. Запрос на изменение методичек не запускает занятия.

Stage 2 передаёт существующий принятый план и прочие артефакты, отдельное handoff-досье не требуется. Stage 4 и Stage 5 запускаются только отдельным явным запросом; окончание Stage 3 не запускает их автоматически. Общие правила содержатся в [родительском стандарте](../STAGE_COMMON_STANDARD.md).
