# Краткая заметка для продолжения Stage 1

Используй только если работа длительная, её нужно будет продолжить или заметка прямо запрошена. Это не обязательный артефакт и не gate. Если заметка уже есть, обновляй её в разрешённом месте.

```text
Цель, границы и заданный состав главы:
Канонические COURSE/BLOCK и важные источники:
Что сделано и фактически проверено:
Что осталось, существенные зависимости и следующий шаг:
```

При продолжении сверь заметку с действующими файлами и чужими правками, затем продолжай незавершённое. Не пересоздавай завершённые результаты. Следующий Stage запускается только отдельным поручением.
