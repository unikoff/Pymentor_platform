# Продолжение Stage 1 одной главы

Шаблон для длительной работы или восстановления, не обязательный отчёт каждого шага. Создавай один docs/stage-runs/<run-id>/RUN.md при необходимости; обновляй существующий. [Маршрут](STAGE_FLOW.md) и полные C/B/F определяют работу и приёмку.

- **Задача:** курс, глава, четыре глобальных номера блоков в порядке программы; создание/продолжение/адресная переработка и границы.
- **Вход:** канонические источники, существенные решения по A/B и ограничениям. Ссылки на COURSE/BLOCK вместо копирования.
- **Файлы:** COURSE.md и четыре BLOCK_N.md с точными путями; что сохранено и что ещё не принято.
- **Опись:** N_expected / N_accepted; полная опись и семь полей каждого паспорта находятся в BLOCK, здесь ссылки и недостающее.
- **Проверки F:** покрытие B, соседние уроки, три межблочных стыка, два внешних края, нагрузка и идентичность; фактический результат на текущих версиях.
- **Продолжение:** первый незавершённый шаг, конкретные блокеры и зависимые файлы.
- **Итог:** CHAPTER_STAGE1_ACCEPTED / STAGE_COMPLETE либо STAGE_INCOMPLETE с остатком.

Таблицы работников, admission, очередь и хеши микрошагов не нужны. При изменении рамки перепроверь зависимое. RUN не заменяет F и не доказывает освоение. Итог по [общему шаблону](../START.md#итоговый-ответ), затем остановка; Stage 2 запускается отдельно.
