# Stage 1 — концепция главы и блоков

В одном чате создай или продолжи порученную концепцию: [C1–C4](01_CHAPTER_CONCEPT.md) для главы → [B1–B4](02_BLOCK_CONCEPT.md) для каждого блока → [F1–F3](03_CHAPTER_ACCEPTANCE.md) для сквозной проверки. Рабочий маршрут и критерии — [STAGE_FLOW.md](STAGE_FLOW.md), общие правила — [STAGE_COMMON_STANDARD.md](../STAGE_COMMON_STANDARD.md). Подробные методички и руководства используй, когда нужен соответствующий критерий; [RUN_TEMPLATE](RUN_TEMPLATE.md) — для долгого продолжения.

Вход: курс, глава, аудитория и исходные знания, цель, ограничения, канонические источники и разрешённые пути. Обычный результат — `COURSE.md` и четыре глобально пронумерованных `BLOCK_N.md`, по пять основных дней в каждом и с паспортом каждого обязательного подзанятия. Прямо заданный другой объём или частичный scope соблюдается. Проверяй канонические пути: похожие имена глав не доказывают их совпадения.

Концепты описывают наблюдаемый результат, его предпосылки, подготовку, самостоятельную практику и проверку. Они не являются ни готовой теорией, ни подробным планом Stage 2, ни свидетельством усвоения учеником. Stage 2 получает существующие артефакты и выполняется только по отдельному запуску; то же относится к каждому следующему Stage.

[COURSE_CONCEPT_GUIDE](COURSE_CONCEPT_GUIDE.md) и [BLOCK_CONCEPT_GUIDE](BLOCK_CONCEPT_GUIDE.md) — краткие справки по соответствующим предметным вопросам.
