# Stage 1: локальные указания

Общий договор — [STAGE_COMMON_STANDARD.md](../STAGE_COMMON_STANDARD.md); маршрут этого этапа — [STAGE_FLOW.md](STAGE_FLOW.md). При работе с концептами также применяй инструкции их целевой папки.

Stage 1 проектирует порученную главу и её блоки одним чатом: C1–C4 → B1–B4 для каждого блока → F1–F3. Обычный объём — четыре блока по пять основных учебных дней и все обязательные подзанятия; явно заданный иной объём имеет приоритет. Частичное поручение не расширяй.

Сохраняй действующие концепты, существующие идентичности, `source_file`, прогресс и чужие изменения. Для каждого обязательного занятия нужен содержательный паспорт; общие A и инварианты размещай в главе или блоке и ссылайся на них, в паспорте указывай отличия. RUN нужен только для продолжительной работы или по прямому запросу, не для допуска к шагу.

Результат — разрешённые COURSE и BLOCK с проверенными связями и явным остатком, если есть блокер. План занятия, готовые уроки и исполнение других этапов в Stage 1 не входят. Stage 2 и каждый следующий Stage запускаются отдельно и никогда автоматически.
