# AGENTS.md: Stage 1

Область: концепция заданной главы и четырёх её блоков. Прочитай [общие правила](../AGENTS.md), [маршрут](STAGE_FLOW.md), [README](README.md), затем полные [C](01_CHAPTER_CONCEPT.md), [B](02_BLOCK_CONCEPT.md), [F](03_CHAPTER_ACCEPTANCE.md) перед соответствующими шагами. Точка входа: [stage-1-chapter-design](../../../.agents/skills/stage-1-chapter-design/SKILL.md). При записи в docs/concept инструкции этой папки могут не загружаться автоматически: применимые правила должны быть реально прочитаны.

- Один чат выполняет C1–C4, B1–B4 для каждого блока, F1–F3. Отдельные назначения шагов и чаты не требуются; Stage 2/3 не запускаются.
- Установи главу, четыре глобальных номера в порядке курса, канонические пути, аудиторию, A/B, источники и разрешённую запись. Похожие chapter_01 и chapter_01new не взаимозаменяемы без основания.
- Один активный писатель на файл. Обычные пробелы решай по источникам в разрешённой области; существенный конфликт обозначь у зависимого участка и продолжай доступную работу. Модель и права берутся из текущего запуска, отдельная диспетчеризация не требуется.
- **Предмет:** пять основных учебных дней и все обязательные подзанятия; у каждого семь полей, включая самостоятельную практику, критерий и обоснованную глубину теории. Числовой диапазон необязателен; общей нормы или резервного минимума нет. A имеет статус и источник, новое объясняется и опробуется до применения. Сохраняй N, строковые номера и прежние ID.
- **Идентичность:** `display_number`, `title`, название/порядок блока и позиция урока могут меняться; `lesson_id` бери **из авторитетной реализации**, где `_stable_lesson_id()` хеширует `_lesson_identity_source()` от относительного source path с учётом алиасов (`services/core-api/pymentor_core/adapters/course_local/identity.py`, `services/core-api/pymentor_core/adapters/course_local/catalog.py`). ID независим от позиции, **но зависит от канонического пути**. Вести mapping прежний→новый номер/title ↔ существующий lesson_id ↔ canonical identity source / alias ↔ физический путь. При разбиении «03» на «03.1–03.3» сохранять ID/пути существующих уроков. Для **нового запланированного занятия**, у которого ещё нет runtime `lesson_id`, допустима запись в паспорте **«ID требует назначения по действующей схеме»** с владельцем реализации и этапом проверки/создания mapping при включении в каталог; это **не Stage 1 blocker и не BETA_GAP**. Обычный путь сохранять: физический перенос/переименование может изменить хеш и `lesson_id`. При необходимом переносе отдельно уполномоченный владелец реализации должен добавить/проверить alias/identity mapping и миграцию прогресса; Stage 1 фиксирует потребность, но не выполняет её, не меняет файлы, routes, progress ID или схему. При вставке/удалении/перестановке пересобрать последовательность, prerequisite/A→B, возрастающую сложность, COURSE↔BLOCK, N-паспорта и три межблочных перехода; чистый display rename — только корректировка отображения и ссылок по mapping. `BETA_GAP: LESSON_IDENTITY_UNVERIFIED` — **только для существующего/реализованного урока**, когда `lesson_id` ожидается, но canonical identity source/alias не подтверждается; запросить минимальную карту, не менять схему приложения.
- **Приёмка:** F1–F3 проверяет полное покрытие B, 3 внутренних и 2 внешних границы блоков, **все** межурочные связи, рост сложности и идентичности. `STAGE_COMPLETE` только при COURSE 1/1, BLOCK 4/4, `N_accepted=N_expected`, обязательных PASS на актуальных версиях и отсутствии препятствующих `FAIL/BLOCKED/NOT_CHECKED`; иначе `STAGE_INCOMPLETE` с остатком/владельцем. Прямая авторская цель в мандате не требует повторного согласования. Документальная готовность не доказывает фактическую успеваемость.
- Записывай только разрешённые COURSE.md и четыре BLOCK_N.md; краткий RUN нужен для восстановления/длительной работы. Не создавай PLAN, TSX, код, миграции и новые ID, не меняй Git или прогресс при проектировании.
- Итог по [шаблону](../START.md#итоговый-ответ): пять файлов, N/N, F или точный остаток. При продолжении сверь реальные MD и начни с незавершённого. После результата остановись.
