# Продолжение работы одного Stage

Используй только для длительного набора или восстановления после прерывания. Обновляй существующую запись; отдельные журналы шагов и дубликаты сводок не нужны.

- Stage и объём: …
- Источники и пути результатов: …
- Завершено: …
- Следующее конкретное действие: …
- Фактические проверки: версия/набор, покрытие, результат или ссылка на сохранённое свидетельство.
- Блокеры и непроверенное: …

Для большого набора можно заменить список завершённого таблицей «занятие | результат/путь | статус/остаток». Свидетельство общего build хранится один раз с покрытием. RUN фиксирует состояние, но не доказывает его: после прерывания сверь изменившиеся файлы и продолжи незавершённое. В конце выбранного Stage остановись.
