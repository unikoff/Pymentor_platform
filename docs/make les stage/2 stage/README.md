# Stage 2 — проектирование занятий

Один форк пользователя выполняет Stage 2 одного конкретного занятия. Вход — его паспорт Stage 1; результат — один проверенный MD-план. Другие занятия этим форком не обрабатываются. [Маршрут](STAGE_FLOW.md), [общий стандарт](../STAGE_COMMON_STANDARD.md), [выбор запуска](../START.md).

Внутренние шаги сохраняются: [P1: рамка](01_PLAN_FRAME.md) → [P2: объяснение](02_THEORY_ROUTE.md) → [P3: практика](03_PRACTICE_ROUTE.md) → [P4: приёмка](04_PLAN_ACCEPTANCE.md). Они уточняют один файл без отдельных сообщений и отчётов. Переход к Stage 3 выполняется отдельным запуском по принятому плану.
