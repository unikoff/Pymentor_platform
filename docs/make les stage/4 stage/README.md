# Stage 4 — экспертная проверка и доработка

[Методичка](LESSON_REVIEW_GUIDE.md): готовое занятие → конкретные дефекты → адресные исправления → проверка. Отдельный запуск; для аудита без изменений укажи это явно.

Запуск и границы — в [START](../START.md) и [общем стандарте](../AGENTS.md). Итог по [общему шаблону](../START.md#итоговый-ответ) с находками/исправлениями и фактическими проверками, без отдельного дублирующего отчёта. После порученного ревью остановись; Stage 5 не запускается автоматически.
