# Прежний маршрут StudyHub

Ученическое прохождение перенесено в [Stage 5](../5%20stage/STUDYHUB_WORKFLOW.md). Действует компактный маршрут одного чата: теория, практика в одном проекте, знания, ревью и поурочный коммит.

Программы из заданий допускают функциональную замену через CLI/API/агент без обязательного Computer Use; применяй актуальный раздел методички Stage 5, а не исторические требования ручной проверки GUI.

При зацикливании действует разрешённая консультация одного субагента GPT-6.1 Terra из методички Stage 5; повторно разрешение пользователя не требуется.

Исторические методички доступны в Git: `0f050190:docs/STUDYHUB_WORKFLOW.md` и `bfa2eecc:docs/make les stage/review stage/STUDYHUB_LEARNING_WORKFLOW.md`. Этот указатель сохраняет старые ссылки и не добавляет второй набор требований.
