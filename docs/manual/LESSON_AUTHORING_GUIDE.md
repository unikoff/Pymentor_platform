# Создание и переработка занятий Pymentor

**Совместимый диспетчер AUTHORING.** Прежние ссылки, включая конкретные разделы, продолжают вести сюда. Действующий маршрут — [LES_MAIN: M1–M5](../make%20les%20stage/3%20stage/README.md). После принятого MD из [PLAN](LESSON_PLAN_GUIDE.md) пять проходов последовательно готовят TSX, практику, редактуру, учебные визуалы и итоговую авторскую приёмку. Ниже каждый прежний раздел указывает актуальную инструкцию; этот диспетчер не задаёт отдельную параллельную методику.

Для запроса **полностью готового занятия** выполни M1 → M2 → M3 → M4 → M5 в разрешённых файлах или продолжи с первой неподтверждённой стадии готового артефакта. Не останавливайся после M1/M2 и не объявляй локальную приёмку общим PASS. Если явно заказан только Mn, заверши лишь его границу. Внешний [REVIEW](LESSON_REVIEW_GUIDE.md) — самостоятельная перепроверка готового занятия после M5, не шестой проход MAIN.

Независимый [StudyHub workflow](STUDYHUB_LEARNING_WORKFLOW.md) даёт подтверждённые результаты ученика; его планы и будущие шаги не считаются уже выполненными.

## 4. Объём

**Действующая норма — [M3, раздел о подсчёте учтённой видимой TSX-теории](../make%20les%20stage/3%20stage/03_CONTENT_EDIT.md)**; финальный пересчёт после вставок — [M4, раздел 7](../make%20les%20stage/3%20stage/04_VISUAL_INTERACTIVE.md) и [M5, раздел 5](../make%20les%20stage/3%20stage/05_LESSON_ACCEPTANCE.md). M1/M2 пишут полный черновик без потолка. Предел задаёт паспорт, для нового паспорта диапазон обязателен; у установленного унаследованного паспорта допускается маркированный резерв, а обоснованный диапазон ниже 1000 принимается без нового исключения. **Квоту слов практики не вводи.**
