# Методички Pymentor

Эти руководства расположены по порядку создания учебных материалов:

1. [Общая концепция курса](COURSE_CONCEPT_GUIDE.md) задаёт цель курса и карту блоков.
2. [Концепт блока](BLOCK_CONCEPT_GUIDE.md) раскладывает карту курса на занятия и их результаты.
3. [План занятия](LESSON_PLAN_GUIDE.md) превращает паспорт занятия в последовательность теории и практики.
4. [Создание занятия](LESSON_AUTHORING_GUIDE.md) задаёт работу над теорией, TSX, практикой и проверкой на платформе.
5. [Перепроверка и доработка готового занятия](LESSON_REVIEW_GUIDE.md) применяется сразу после создания: проверяет путь ученика, исправляет ошибки и подтверждает результат. Это этап 4 общего процесса.

[Реестр повторяющихся ошибок](LESSON_REVIEW_FINDINGS.md) содержит основание методички перепроверки: замечания из чата «М занятия», группы причин и источники без повторного учёта дублей.

Для прохождения курса в учебном репозитории StudyHub предназначена [инструкция по учебному процессу](STUDYHUB_LEARNING_WORKFLOW.md).
