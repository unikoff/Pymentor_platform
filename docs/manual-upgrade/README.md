## Согласованные уточнения второго раунда

- Будущие курс, блок и план могут использовать явно планируемую A с прослеживаемой подготовкой; она не выдаётся за фактическую изученность или существующее состояние проекта.
- Новый паспорт задаёт обязательный диапазон теории и причину. Общий ориентир не нормализует пропуск; fallback разрешён для установленного унаследованного паспорта. Обоснованный диапазон ниже 1000 слов не требует повторного исключения.
- AUTHORING проверяет широкий/узкий рендер, REVIEW дополнительно половину контейнера и границы перестройки. PASS, FAIL и НЕ ПРОВЕРЕНО различаются по фактическим свидетельствам.
- Описание локального критерия согласовано с текущим `ManualPracticeTask.result` и `practiceTask.result ?? exercise.result`; код платформы в этом раунде не менялся.
- В StudyHub уточнены восстановление прежнего состояния, фактические знания, записи без дублей и проверка неопределённого исхода побочных действий/commit/push без расширения полномочий.
