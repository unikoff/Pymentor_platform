## TOP_FINDINGS

**Закрыто — AUTHORING §7, локальный критерий.** Новый текст и пример используют поддерживаемое `tasks[].result` для текущей карточки; `exercise.result` остаётся суммарным. Инструкция отдельно требует проверить выдачу и фактическое отображение. Независимая проверка `frontend/src/features/learning/types.ts` (`ManualPracticeTask.result?: string`) и `frontend/src/features/learning/practice/SelfCheckPanel.tsx:259` (`practiceTask.result ?? exercise.result`) подтверждает корректность описанного исходного контракта. Исправлять UI без наблюдаемого дефекта не требуется.

**Закрыто — диапазон паспорта (AUTHORING §4, REVIEW §1).** Новый паспорт без обязательного диапазона остаётся незакрытой зависимостью BLOCK/PLAN. Общий резерв 1000 / 1400–2000 применяется лишь к явно унаследованному паспорту без диапазона; факт отсутствия поля не доказывает его происхождение. Оба текста согласованы с CONTRACT п. 19.

**Закрыто — планируемая A для диапазона <1000 (AUTHORING §§2, 4, REVIEW §§1, 5).** При проектировании будущего маршрута допускается явно подготовленная планируемая A с предшествующим B/паспортом, местом подготовки и условием применения. Ни один GUIDE не объявляет её изученной. Для реализуемого урока предусмотрена проверка доступности требуемой подготовки и фактической A проекта; без неё нет подтверждённого PASS.
