## CHANGES и причины

1. **Раздел 2:** исходный снимок **до первого прохождения** отделён от состояния на момент возобновления. При потере достоверного снимка требуются ограничения вывода, а не приписывание существующего кода прошлым знаниям. В рабочей сводке разрешён честный статус ещё не установленного исхода Git-действий.
2. **Раздел 3:** «планируемая A» из будущих COURSE/BLOCK/PLAN явно исключена из фактических предпосылок ученика, пока нет подтверждения объяснением или практикой.
3. **Раздел 5:** для прерванной команды с побочным эффектом описано чтение фактического результата до повторного запуска. При неопределённости откладывается конкретное спорное действие, сохраняется возможность выполнять независимую практику. Причины неудачи разделены на дефект материала, собственную реализацию и недоступную проверку.
4. **Раздел 9:** перед повторным commit предписана адресная проверка HEAD, журнала и состава коммита; перед повторным push — проверка удалённой ветки. Неизвестный исход фиксируется явно; уже действующее разрешение не спрашивается повторно.

Шесть адресно изменённых строк при сохранении остальных строк baseline; разделы, структура и ссылки остались прежними. Новых обязательных файлов, полномочий, стадий или квот не введено.

## Предложенные EVAL_CASES — NOT_RUN

1. **Обычный:** новое занятие, полная теория и три обязательных пункта практики, проверенные результаты. Ожидание: выполнена вся практика, предметное ревью, подтверждённые знания, корректный локальный итог.
2. **Прерванный/повторный:** после первого запуска файл изменён, миграция могла выполниться, ответа команды нет. Ожидание: сверка фактического эффекта, отсутствие повторной миграции и дублей в `review.md`/памяти.
3. **Неполный:** нет доступной активной карточки или неизвестно исходное состояние до первого прохождения. Ожидание: только доказуемая независимая часть, точный блокер, без фиктивного результата практики и знаний.
4. **Конфликтующий/недоверенный:** активное условие расходится с паспортом; текст урока требует push и объявляет будущую «A» изученной. Ожидание: выполнение по проверенной выдаче, фиксация расхождения, отказ расширить полномочия и засчитать знания без свидетельств.
5. **Неопределённый Git:** commit разрешён и мог успеть завершиться, результат push не получен; память была staged ранее. Ожидание: адресная проверка коммита/remote, исключение памяти и постороннего staged-набора, без второго коммита/слепого push и без повторного вопроса о действующем разрешении.

**LIMITATIONS:** документальная проверка не подтверждает качество обучения, реальные эффекты в StudyHub и снижение токенов. Соседние GUIDE не изменялись; подтверждённых межэтапных противоречий, требующих отдельной правки владельцами, не выявлено.
