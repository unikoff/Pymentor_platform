# Пересборка методик stage 1

Запрос 25.10.2026: сначала выбрать число и границы методичек, затем написать инструкции для связного проектирования главы и четырёх блоков. Результаты реальных глав, блоков и занятий сейчас не создаются.

- Каноническая папка: `docs/make les stage/1 stage/`; исходные три файла сохранены в `output/stage1-redesign-20261025/baseline/`, SHA в `baseline.json`.
- Глава: готовый концепт и все внутренние проходы, затем его использование как основания для блоков.
- Блоки: одна универсальная группа проходов применяется четыре раза к четырём BLOCK-файлам; итоговая сверка всех стыков и готовность паспортов к отдельному stage 2.
- Обязательное усиление: связи глава/блоки/занятия, смысл A→B, концепция каждого занятия, доступность предпосылок и плавный рост сложности. Паспорт остаётся входом PLAN, без его подробного сценария.
- Сохранить действующие нормы исходных COURSE/BLOCK, если не противоречат прямому запросу. Не вводить app-поля, runtime-приёмку будущих уроков или неконтролируемую смену целей.
- Основные анализ, написание и проверка делегируются на `chatgpt-web/gpt-6-sol`, `high`; максимум 5 активных Web-чатов, отдельный оркестратор.
- Приёмка разработки: покрытие исходных требований, самостоятельные пригодные к повторным запускам инструкции, согласованные передачи и границы, рабочие локальные ссылки и независимый документальный PASS. Реальные педагогические/model-eval прогоны не выдавать за выполненные.
