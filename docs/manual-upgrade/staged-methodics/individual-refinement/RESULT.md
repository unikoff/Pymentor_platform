## Оркестрация и источники

Девять отдельных редакторских проходов и три независимых проверяющих прохода выполнены на **GPT-6 Sol Web, high**. Редакторская очередь: пять, затем четыре документа; одновременно максимум четыре исполнителя и оркестратор. Специализированные инструкции methodist/check и применимый SKILL были прочитаны и переданы исполнителям содержимым. Статусы и контрольные суммы отражены в итоговых отчётах.

Уточнения опираются на текущие [документы GPT-6 Sol](https://developers.openai.com/api/docs/models/gpt-6-sol), [официальные рекомендации по промптингу семейства](https://developers.openai.com/api/docs/guides/latest-model#prompting-best-practices) и проверенные локальные компоненты/runner. Свойства API не приравнивались к возможностям Web; отдельная доказанная формула промптинга Sol Web High и измеренный прирост качества не заявляются. Инструкции конкретизируют вход, границы, результат, локальную приёмку, неполные данные и возобновление без повторного выполнения принятого.
