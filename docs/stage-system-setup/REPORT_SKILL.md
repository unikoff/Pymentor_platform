Детальная процедура остаётся в `BATCH_WORKFLOW.md`, предметные правила — в P1–P4/M1–M5. Не добавлены скрипты, интерфейсные метаданные, учебные материалы или новые конфиги. Для будущих стадий предусмотрено точечное утверждаемое соответствие «stage → профиль → источники/проходы → приёмка»; текущая версия подключает **только 2 и 3**.
