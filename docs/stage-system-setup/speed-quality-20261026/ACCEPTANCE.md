# Итог: баланс скорости и качества Stage 2/3

**COMPLETE — обновление инфраструктуры.** Реальные занятия не запускались/не изменялись этой задачей; прежний незавершённый Stage 3 этим документом не принимается. Измеренное ускорение и качество следующего прогона — NOT_VERIFIED.

## Что изменено

- Общий Skill, AGENTS, BATCH_WORKFLOW, RUN_TEMPLATE, оба профиля, локальные Stage 2/3 инструкции и методички согласованы. Один автор получает один урок, без личной очереди и агентов на каждый P/M-проход.
- Убраны обязательные повторные preflight, перечитывания неизменных источников и полные аудиты. Первый результат — смысловая правка/новый материал либо точный blocker. Ориентир первого сохранённого REWORK результата 10–15 минут доступной работы после чтения входов — диагностический, не автоотмена/гарантия модели.
- Владение общим файлом ограничено короткой записью/интеграцией. Автор не держит lease и слот в ожидании сборки; возвращает LOCAL_READY, если осталось только общее техническое завершение.
- Один интегратор проверяет итоговый набор. Общие backend/frontend/build/API результаты не размножаются на каждого автора. Четыре PASS M5, осмотр каждого урока и всех обязательных задач остаются; общий результат требует совпадения версии/зависимостей и явного покрытия IDs.
- LOCAL_READY не входит в N_accepted и не означает COMPLETE. Автор отвечает за содержание, Coordinator закрывает итог по фактическим доказательствам интегратора. Методички README/AGENTS/M5 явно отражают этот переход.
- После средового отказа — одна ограниченная диагностика и точный blocker, без перебора одинаковых bootstrap. Доступное редактирование продолжается. После правки повторяются только затронутые проверки.
- Helper принимает JSON одного занятия и обязательный --lesson-id, требует change/scope/acceptance и защищает входные файлы. Не запускает агентов, не меняет политику.
