## CHANGES И ОБОСНОВАНИЕ

1. **CREATE / REWORK / RESUME.** Для нового, содержательного существующего и прерванного MD предусмотрены разные действия. При переработке сначала фиксируют `место → наблюдаемый дефект → влияние на B → адресная правка → что теперь сможет продемонстрировать ученик`. Сильные фрагменты сохраняют с основанием `KEEP`; нет квоты на diff, числа правок и отчётов после каждого прохода.
2. **Разные обязанности P-проходов.** P1 исправляет цель, границы и крупный маршрут; P2 — предпосылки и порядок объяснений; P3 — собственную работу ученика и локальные критерии; P4 — целостность и приёмку. Проверки не подменяют учебную операцию.
3. **Практика с ростом самостоятельности.** Однотипные задания со сменой значений больше не считаются прогрессией без различающего учебного результата. Действия выбирают под B: прогноз, трассировка, объяснение, поиск ошибки, самостоятельная сборка и перенос, если они подготовлены и необходимы.
4. **Смысловой ритм будущего MAIN.** Не более двух последовательных читаемых абзацев без содержательного интерактива **или** учебного визуала. Цепочка `TrueFalse → Note → TrueFalse` на близкую тему сама по себе не развивает понимание: между проверками требуется объяснение механизма и новое осмысленное действие. Не навязывается механическое чередование компонентов.
5. **Сохранены предметные инварианты.** Строковые номера (включая `13.1`), A со статусом доказанности, паспорт B/формат/диапазон и правила наследования, буквальный YouTube-комментарий, два связанных маршрута с объяснением после них, один MD на занятие и граница между PLAN и MAIN. Права и параметры Web-runtime берутся из effective task policy, не зашиты в stage 2.

**Пример диагностической разницы:** до улучшения два близких True/False о `run()` и `handle_*` с промежуточной Note проверяли преимущественно узнавание утверждений. Теперь при соответствии B методика требует сначала объяснить прохождение команды и изменение состояния (P2), затем дать самому ученику трассировку и прогноз на отличающемся вводе (P3), а на P4 удостовериться в проверяемом результате. Сам [Lesson21.tsx](../../../frontend/src/lessons/chapter_02/block_05/Lesson21.tsx) остался без изменений.
