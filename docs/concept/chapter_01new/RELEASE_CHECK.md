## Точка B

Исторический `main.py` прочитан непосредственно из `383c212bda040269b497ea9c504ffd474dfe3248` локального репозитория StudyHub. Все 21 сигнатуры функций из ответов занятий найдены и совпадают с этим snapshot. Отдельно выполнены операции создания, ID от максимального, точного поиска, повторного завершения, поиска названия, форматирования, суммы и статистики.

`build_statistics(tasks)` возвращает словарь ровно с ключами `total`, `completed`, `left`. `completion_percent(statistics)` принимает один словарь. Пустой случай возвращает `0.0`, треть — `33.3`. Проверка этих интерфейсов теперь входит и в обучение, и в финальную приёмку.

Сохраняются один `main.py`, 21 функция, один прямой `run()`, семь команд, четыре поля, память одного процесса и прежний формат карточки. Единственное согласованное отличие настройки — перенос `.venv` во вторую главу с соответствующим запуском в README и правилами `.gitignore`. История и SHA ученического проекта могут отличаться; это не разрешение менять функциональные договоры.
