# Stage 3: создание одного занятия

В пользовательском форке выполни только Stage 3 одного конкретного занятия. Полные содержательные требования восстановлены из `76fc57bf0`: [Stage 3](../../../docs/make%20les%20stage/3%20stage/README.md). Перед работой прочитай полную методичку текущего шага. Skill не заменяет требования к глубине, примерам, схемам, интерактивам и приёмке. Не удаляй предусмотренный полезный визуал только потому, что его можно пересказать текстом.

Установи цель по последнему актуальному поручению: курс, глава/блок, одно занятие, его паспорт, принятый MD-план, TSX и точная запись практики. История родительского чата, старые очереди и ответы не меняют назначение. ID устанавливай по источнику, будущий runtime ID не выдумывай. Список занятий не превращай в очередь: до записи нужна однозначная цель. Отсутствие принятого плана обозначь как зависимость от отдельного Stage 2; не создавай его внутри Stage 3.

Прочитай [общие правила](../../../docs/make%20les%20stage/AGENTS.md) и [маршрут M1–M5](../../../docs/make%20les%20stage/3%20stage/STAGE_FLOW.md). Все внутренние методички и шаги сохраняются и выполняются тем же чатом без отдельных назначений. Явно ограниченный шаг или аудит без правок остаётся в его границах.

С начала Stage 3 применяй [требования понятности](../../../docs/make%20les%20stage/3%20stage/05_LESSON_ACCEPTANCE.md#приёмка-понятности): действие ученика связано с опорой, полным примером/визуалом и наблюдаемым результатом. Уточняй эту связь в существующем плане и материале, без нового реестра на каждом шаге. Условие объясняет задачу простыми словами, ТЗ технически задаёт её по порядку, неизвестные средства подготовлены до обязательного применения. Визуал создаётся с немедленной проверкой и исправлением; M4/M5 сохраняют свой охват.

На Stage 3 для M1 используй [stage-3-theory-author](../stage-3-theory-author/SKILL.md), для M2 — [stage-3-practice-author](../stage-3-practice-author/SKILL.md). Это инструменты того же автора и шага, без новых чатов, отдельных отчётов и изменения границ этапа.

Stage 3 создаёт теорию/практику этого урока и закрывает содержательную, визуальную и четыре технических проверки. При первой схеме или интерактиве прочитай [skill создания визуального контента](../stage-3-visual-author/SKILL.md) и используй его сразу; M4 сохраняется для проверки композиции всего урока. Осмотр — во встроенном браузере только локальной платформы по Stage 3; непроверенное не является PASS. Форк не изолирует общие файлы: применяй точечные правки только своей записи, сохраняй чужие изменения, не очищай общий diff и не жди окончания чужих уроков. Если результаты проверки не относятся к текущей версии, не засчитывай их.

После приёмки или конкретного блокера сообщи занятие, путь результата, фактические проверки и остаток. Не начинай другой урок, следующий Stage или создание новых чатов/форков. Для продолжения своего урока используй сохранённые файлы без повторной генерации готовых частей.
