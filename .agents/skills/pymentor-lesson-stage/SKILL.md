# Одно занятие, один Stage

Восстанови цель по последнему актуальному поручению: Stage, курс, глава/блок, одно занятие, его паспорт и целевой MD; при Stage 3 — принятый план, TSX и точная запись практики. История родительского чата, прежние очереди и ответы не меняют назначение. ID устанавливай по источнику, будущий runtime ID не выдумывай. Несколько занятий не превращай в очередь: сначала нужна однозначная цель этого форка.

Прочитай [общий стандарт](../../../docs/make%20les%20stage/STAGE_COMMON_STANDARD.md) и только выбранный маршрут: [Stage 2, P1–P4](../../../docs/make%20les%20stage/2%20stage/STAGE_FLOW.md) либо [Stage 3, M1–M5](../../../docs/make%20les%20stage/3%20stage/STAGE_FLOW.md). Все внутренние методички и шаги сохраняются, выполняются одним чатом без отдельных назначений. Явно ограниченный шаг остаётся в его границах.

На Stage 3 для M1 используй [pymentor-lesson-theory](../pymentor-lesson-theory/SKILL.md), для M2 — [pymentor-lesson-practice](../pymentor-lesson-practice/SKILL.md). Это инструменты того же автора и шага, без новых чатов, отдельных отчётов и изменения границ этапа.

Stage 2 сохраняет и принимает один MD-план. Stage 3 создаёт теорию/практику этого урока и закрывает содержательную, визуальную и четыре технических проверки. При первой схеме или интерактиве прочитай [skill создания визуального контента](../pymentor-lesson-visual/SKILL.md) и используй его сразу; M4 сохраняется для проверки композиции всего урока. Осмотр — во встроенном браузере только локальной платформы по Stage 3; непроверенное не является PASS. Форк не изолирует общие файлы: применяй точечные правки только своей записи, сохраняй чужие изменения, не очищай общий diff и не жди окончания чужих уроков. Если результаты проверки не относятся к текущей версии, не засчитывай их.

После приёмки или конкретного блокера сообщи занятие, путь результата, фактические проверки и остаток. Не начинай другой урок, следующий Stage или создание новых чатов/форков. Для продолжения своего урока используй сохранённые файлы без повторной генерации готовых частей.
