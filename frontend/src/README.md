# Структура `src`

- `app/` — запуск React-приложения, его сборка и общие стили; панели оболочки сгруппированы в `app/workspace/`.
- `features/` — функциональные области: авторизация, обучение, аккаунт и админ-панель. API, состояние и типы предметной области находятся рядом с функцией; `index.ts` каждой области задаёт её публичные импорты для `app/`.
- `shared/` — повторно используемые UI-компоненты, API-клиент, общие контракты и утилиты; этот слой не зависит от `features/`.
- `lessons/` — реестр и материалы уроков, сгруппированные по главам.

Стили подключаются через `app/styles.css` в порядке, соответствующем прежней каскадной очередности. Новую логику следует размещать рядом с функцией-владельцем; в `shared/` переносить только код, который действительно используется несколькими областями.
