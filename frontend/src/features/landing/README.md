# Лендинг

- `BackendLandingPage.tsx`, `LandingPages.tsx`, `PersonalDataPage.tsx` — страницы и существующие точки входа.
- `sections/` — крупные блоки главной страницы.
- `components/` — общие компоненты и вспомогательная логика.
- `styles/` — стили страниц, секций и компонентов; `tokens.css` — общая шкала типографики и отступов лендинга.
- `assets/` — изображения и видео.

Для основных заголовков секций и заголовков вкладок обучения используйте `--landing-heading-*`, для главного заголовка страницы — `--landing-hero-size`. Основные отступы секций задаются через `--landing-section-padding`, размер и межстрочный интервал вводного текста — через `--landing-copy-*`. Исключения допустимы для внутренних элементов, когда этого требует их функция или компоновка. Токены ограничены корнем `.backend-landing` и не меняют стили учебной платформы.
